# B1A storage ownership baseline

Date: 2026-08-26

This inventory is the ownership boundary for Batch 1A. The diagnostic scanner reads directory entries and file metadata only. It does not open file contents, connect to SQLite, follow symbolic links/reparse points, create missing directories, or call any cleanup, repair, migration, checkpoint, compaction, truncate, or vacuum path.

## Diagnostic policy

Thresholds are centralized in `packages/core/src/storage-health.ts` by category. They classify observations as `HEALTHY`, `WARNING`, or `CRITICAL`; they are not deletion policy and do not authorize maintenance. Missing paths are reported as `NOT_DISCOVERED`, inaccessible paths as `INACCESSIBLE`, and intentionally absent categories as `NOT_APPLICABLE`.

Each target is bounded independently by depth, inspected-item count, elapsed time, and largest-item result count. Roots are scanned sequentially to avoid a disk I/O burst. Symbolic links and reparse points are counted as skipped and are never followed.
