对应任务：录井小雪 0.8 RC3 第三阶段 · 第六节（Windows RC3 安装版 GUI 验收）与补充任务书第十节。
验收对象：`录井小雪-0.8.0-rc.3-win-x64.exe`（330,658,590 字节，SHA-256 `B2BBDB7F…B14681`，未签名）。
验收环境：Windows 25H2，2560×1600，基线缩放 150%，Word 未安装（WPS 位于 `C:\Program Files (x86)\Kingsoft\office6`），无真实 U 盘（`subst U:` 替代）、无管理员权限创建 SMB 共享（`\\127.0.0.1\D$` 管理共享替代 UNC）。
