# 已知限制

- PDF 仅支持原生文本或可复制文字的文件，不支持扫描件 OCR、手写资料和复杂版面重建。
- 知识检索当前采用本地关键词排序，不是完整向量 RAG；同义词和语义召回仍需扩充评估集。
- 自动审核属于辅助检查，地质认识、层位划分、油气显示解释和关键数据必须由专业人员复核。
- 当前专业回归样例为脱敏或人工构造案例，尚需公司专家确认规则阈值。
- 小雪桌宠以 2.5D 形象和状态交互为主，3D 模型与动作仍在优化。
- Provider 可用性取决于账号、额度、网络和企业模型服务配置。
- 审核历史复用 Session SQLite metadata，适合桌面 MVP；跨用户查询和集中治理需后续独立业务表设计。
