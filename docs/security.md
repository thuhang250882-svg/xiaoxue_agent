# 数据安全

## 数据边界
- 业务资料默认在本机解析，不上传到知识库以外的位置。
- 调用远程 Provider 时，用户提交给模型的文本可能离开本机；企业部署应使用批准的内网模型服务。
- 审核历史只保存结构化结果、文件元数据和受控路径，不保存大型二进制。
- 删除历史记录默认不删除原始业务文件。

## 发布检查
- 扫描 API Key、Token、密码和私钥。
- 扫描开发机用户名、盘符绝对路径和临时目录。
- 排除真实井名、真实合同、标书及其他敏感业务样本。
- 测试样例必须人工构造或完成脱敏。
- 检查导出目录、日志、缓存和测试临时文件未进入版本控制。

## 知识引用
知识检索只返回当前生效版本。每个命中包含资料编号、版本、章节或段落、来源路径、摘录和更新时间。未命中可靠来源时必须明确提示人工复核，不得编造标准编号。
