录井小雪内网版安装说明
========================

适用范围：仅用于单位内网中受管理的少量 Windows 电脑。

一、安装前核验

1. 请从软件发布者本人或单位可信共享目录取得本文件夹。
2. 发布者证书 SHA-1 指纹必须为：
   72D0E59840C1B8EA8FCF8B8D263D48827120C977
3. 不要安装来源不明、指纹不同的证书。

二、首次安装

1. 右键“install-xiaoxue-internal-certificate.cmd”，选择“以管理员身份运行”。
2. 看到“Certificate installation completed”后，再运行录井小雪安装程序。
3. 在安装程序属性的“数字签名”页中，发布者应为“录井小雪内部软件发布者”。

三、后续升级

只要证书未过期且指纹未变化，同一台电脑无需重复安装证书，可直接安装由同一证书签名的新版本。

四、安全说明

证书安装程序只分发公钥证书，不包含签名私钥。将证书加入“受信任的根证书颁发机构”和
“受信任的发布者”后，Windows 会信任由该证书签名的软件。因此证书只能通过单位可信渠道分发，
签名私钥必须只保存在发布电脑上，不得复制到客户端或普通共享目录。
