# 地质录井报告审核智能体

MVP 目标：支持用户上传地质录井报告及配套表格，自动解析并执行基础规则审核，输出可追溯的问题清单和修改建议。

## 审核流程

1. 文件解析：docx、xlsx 优先，pdf/txt/csv 作为补充。
2. 资料分类：报告正文、油气显示解释表、综合记录、地质设计、完井卡片、测井解释成果等。
3. 字段抽取：井号、井深、层位、井段、岩性、气测异常、显示级别、结论建议。
4. 规则审核：结构、基础信息、分层、岩性、油气显示、气测、术语、一致性。
5. RAG 辅助：检索标准规范、公司制度、模板、历史报告和专家经验。
6. 结果输出：问题清单、严重程度、修改建议、依据来源和人工确认标记。

## 边界

当前阶段不做实时井控预警、视频监控、安全行为识别和现场工况监控。
