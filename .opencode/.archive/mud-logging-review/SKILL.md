# 地质录井报告审核

审核地质录井技术报告，按照行业标准逐项检查数据一致性、描述规范性和结论逻辑性。

## 审核依据

- SY/T 5788.1 油气探井地质录井规程 总则
- SY/T 5788.2 岩屑录井规程
- SY/T 5788.3 气测录井规程
- SY/T 5788.4 工程录井规程
- SY/T 6611 录井资料质量控制
- GB/T 21074 地质编录规范

## 审核流程

### 第一步：基本信息校验
1. 井号是否与任务书/设计一致
2. 井别（探井/评价井/开发井）是否正确
3. 地理位置、构造位置描述是否准确
4. 开钻日期、完钻日期、录井井段是否合理
5. 录井单位、录井队号、录井人员信息完整

### 第二步：地层信息校验
1. 地层名称与区域地质资料是否一致
2. 地层界线深度与岩屑描述是否对应
3. 地层厚度计算是否正确
4. 地层代号使用是否规范（如 T1k = 三叠系库车组）

### 第三步：岩性描述审核
1. 岩性定名是否符合 SY/T 5788.2 规范
2. 岩屑百分含量与岩性描述是否对应
3. 颜色描述是否使用标准色卡术语
4. 矿物成分、结构构造描述是否完整
5. 含油气性描述（荧光级别、含油产状）是否规范

### 第四步：气测数据审核
1. 全烃基值与异常值判别是否合理
2. 组分数据（C1-C5）与全烃是否协调
3. 气测异常与岩性、钻时的对应关系
4. 后效气测数据与油气层判别是否一致

### 第五步：工程参数审核
1. 钻时数据与岩性变化是否对应
2. 钻井液性能参数变化是否合理
3. 井斜数据与井身质量评价是否准确
4. 井径、井温数据是否完整

### 第六步：结论审核
1. 油气水层综合判别结论是否与数据支撑一致
2. 地层评价结论是否有充分证据
3. 建议与下一步措施是否合理
4. 录井综合图与文字报告是否对应

## 输出格式

对每个发现的问题，输出：

```
【问题位置】章节/页码/段落
【问题描述】具体描述发现的问题
【严重程度】严重/一般/建议
【修改建议】具体的修改方向或建议
【依据标准】引用的标准条款号
```

## 常见错误模式

- 井号前后不一致（正文 vs 表格 vs 图件）
- 地层界线深度在不同章节出现矛盾
- 岩性描述与岩屑含量数据不匹配
- 气测异常未与岩性变化建立关联
- 荧光描述缺少级别数据
- 钻时数据与岩性描述不对应
- 结论过度推断（证据不足以支撑）
