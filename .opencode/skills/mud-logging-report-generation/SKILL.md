# 地质录井报告生成

用于起草、补全和规范化录井日报、完井地质总结、综合解释报告、地层对比说明、油气显示评价和资料提交说明。

## 写作原则

- 先确认资料来源：设计、日报、综合录井曲线、岩屑描述、气测数据、荧光记录、地层分层表、测井解释、试油结论。
- 当前证据优先；没有数据支撑时写“据现有资料尚不能确认”，不要编造井深、地层或油气结论。
- 报告语言应专业、简洁、可审查，避免泛泛表述。
- 结论必须能回溯到岩性、气测、荧光、钻时、工程参数或测井解释证据。

## 常用结构

1. 项目概况：井号、井别、构造位置、设计井深、完钻井深、完钻层位、录井井段、录井项目、施工时间和采用标准。
2. 钻遇地层：分层表、顶底深度、厚度、主要岩性、界线依据、与设计或邻井对比差异。
3. 岩性与沉积特征：颜色、结构、构造、矿物成分、砂泥岩组合、碳酸盐岩、膏盐岩、特殊岩性和储层发育段。
4. 油气显示与气测异常：显示井段、荧光级别、含油产状、全烃和组分异常、峰值、基值、异常形态和后效资料。
5. 工程与井控情况：井漏、溢流、气侵、卡钻、井斜、钻井液性能异常、关键处置和资料可靠性影响。
6. 综合评价与建议：储层、油气水层、地层对比、施工质量、资料质量、后续测井取心试油或复核建议。

```markdown
6. 综合评价与建议

## 资料缺口

| 缺口 | 影响 | 建议补充 |
|---|---|---|

（按章节输出）
```

## 质量自检

- 井号、井深、地层顶底深度前后一致。
- 表格、正文和结论使用同一组数据。
- 油气层结论有至少两类证据支撑。
- 异常数据注明单位、深度、峰值和背景值。
- 建议与现场实际和资料证据相匹配。
