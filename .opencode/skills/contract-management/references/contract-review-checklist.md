# 合同审核清单

## 一、合同主体审核

- [ ] 甲方全称、地址、法定代表人准确
- [ ] 乙方全称、地址、法定代表人准确
- [ ] 双方营业执照、资质证书有效
- [ ] 授权代表有合法授权（授权委托书）
- [ ] 开户银行及账号信息准确

## 二、合同标的工作范围

- [ ] 服务内容/货物描述具体明确
- [ ] 技术标准引用正确（行标版本有效）
- [ ] 工作量明确（井深、井号、服务期）
- [ ] 人员/设备配置要求明确
- [ ] 资料提交要求明确（格式、时间、份数）
- [ ] 变更程序约定明确

## 三、价款与支付

- [ ] 合同金额明确（含税/不含税标注）
- [ ] 单价合同的工作量计算方式明确
- [ ] 付款节点和比例合理
- [ ] 发票类型和税率明确
- [ ] 质保金比例和退还条件明确
- [ ] 延期付款是否有利息约定

## 四、工期与进度

- [ ] 开工日期/进场日期明确
- [ ] 竣工/退场日期明确
- [ ] 工期计算方式（自然日/工作日）
- [ ] 延期责任和顺延条件明确
- [ ] 进度报告提交频率

## 五、质量与验收

- [ ] 质量标准引用正确
- [ ] 验收方式明确（初步验收+最终验收）
- [ ] 验收周期明确
- [ ] 不合格处理方式明确
- [ ] 质保期和质保责任明确

## 六、HSE条款

- [ ] 安全责任划分明确
- [ ] HSE管理要求具体
- [ ] 环保要求符合法规
- [ ] 应急预案约定
- [ ] 保险要求明确（类型、保额）

## 七、违约责任

- [ ] 违约情形列举完整
- [ ] 违约金计算方式合理
- [ ] 违约金上限设置（一般不超过合同总价10%-20%）
- [ ] 损失赔偿范围明确
- [ ] 双方违约责任对等

## 八、不可抗力

- [ ] 不可抗力定义范围明确
- [ ] 通知义务和期限约定
- [ ] 证明文件要求
- [ ] 后果处理方式约定
- [ ] 合同解除条件

## 九、争议解决

- [ ] 协商期限约定
- [ ] 仲裁/诉讼选择明确
- [ ] 仲裁机构/管辖法院约定
- [ ] 适用法律明确

## 十、其他条款

- [ ] 保密条款（范围、期限、违约责任）
- [ ] 知识产权条款（技术成果归属）
- [ ] 合同变更程序
- [ ] 合同终止条件
- [ ] 通知送达方式
- [ ] 合同生效条件
- [ ] 附件清单完整

## 十一、特别关注事项

### 录井合同特有
- [ ] 资料所有权归属甲方
- [ ] 异常报告提交时限
- [ ] 设备故障处理约定
- [ ] 人员资质要求

### 钻井合同特有
- [ ] 井下复杂情况处理责任
- [ ] 井控安全责任
- [ ] 钻井液性能指标
- [ ] 固井质量标准

### 采购合同特有
- [ ] 交货方式和运输责任
- [ ] 检验和拒收条件
- [ ] 质保期和售后服务
- [ ] 备品备件供应
