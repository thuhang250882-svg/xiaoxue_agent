# 石油钻探行业合同核心条款起草指南

## 一、工作范围条款

### 录井技术服务合同要点
- 服务内容：综合录井/气测录井/地化录井/岩屑录井
- 服务井号、井别、设计井深
- 服务期限：从设备进场到设备退场
- 技术标准：SY/T 5784、SY/T 6038等行标
- 资料提交：日报、月报、完井总结报告
- 特殊要求：随钻分析、异常预警等

### 钻井工程合同要点
- 钻井深度、井型（直井/定向井/水平井）
- 井身结构：套管程序
- 钻井液体系
- 完井方式
- 设备配置要求

### 条款示例（录井技术服务）
```
乙方应按以下要求提供综合录井技术服务：
1. 服务井号：[井号]，井别：[井别]，设计井深：[深度]m
2. 服务内容：综合录井（含岩屑录井、气测录井、工程录井、地化录井）
3. 技术标准：执行SY/T 5784-2018《石油天然气钻探地质录井规程》
4. 设备配置：综合录井仪1套，满足甲方技术要求
5. 人员配置：录井队长1人、地质录井员2人、气测录井员2人、仪器操作员2人
6. 资料提交：
   （1）录井日报于每日上午8:00前提交
   （2）异常报告于发现异常后2小时内提交
   （3）完井地质总结报告于完井后15个工作日内提交
```

## 二、价款与支付条款

### 常见计价方式
- **按井深计价**：元/米（适用于钻井、录井）
- **按时间计价**：元/天（适用于设备租赁、驻井服务）
- **按工作量计价**：元/层（适用于测井、射孔）
- **总价包干**：适用于设计、咨询类合同

### 付款节点示例
```
1. 预付款：合同签订后10个工作日内支付合同总价的30%
2. 进度款：设备进场、开钻后支付合同总价的30%
3. 验收款：服务完成、资料验收合格后支付合同总价的30%
4. 质保金：验收合格后满6个月无质量问题，支付剩余10%
5. 发票要求：乙方提供增值税专用发票（税率[ ]%）
```

### 注意要点
- 明确含税/不含税
- 付款条件与里程碑挂钩
- 发票类型和税率
- 延期付款利息计算方式

## 三、HSE条款

### 标准条款要点
- HSE管理体系：要求通过HSE认证
- 安全生产责任：明确双方安全责任划分
- 环保要求：废岩屑、废钻井液处理
- 应急预案：井喷、火灾、泄漏等
- 安全培训：入场安全教育
- 保险要求：雇主责任险、第三者责任险

### 条款示例
```
1. 乙方应严格执行甲方的HSE管理规定，施工前需通过甲方HSE审核
2. 乙方应为其员工购买雇主责任险，保额不低于[ ]万元/人
3. 乙方应购买第三者责任险，保额不低于[ ]万元
4. 因乙方原因造成的安全事故，乙方承担全部责任和经济损失
5. 废岩屑、废液处理应符合国家及地方环保法规
6. 发生井喷等紧急情况时，乙方应配合甲方执行应急预案
```

## 四、违约责任条款

### 常见违约情形
- 工期延误：按日扣罚合同总价的0.1%-0.5%
- 质量不合格：返工费用由违约方承担
- 擅自变更：未按审批程序变更设计方案
- 资料延误：影响后续施工的资料未按时提交

### 条款示例
```
1. 乙方未按合同约定期限完成服务的，每延误一日，应向甲方支付合同总价0.3%的违约金，最高不超过合同总价的10%
2. 因乙方原因导致录井资料不合格需返工的，返工费用由乙方承担
3. 因乙方原因导致井喷等重大事故的，乙方承担相应赔偿责任
4. 甲方未按约定付款的，每延误一日，应向乙方支付欠付款0.3%的违约金
```

## 五、不可抗力条款

### 标准定义
不可抗力包括但不限于：地震、洪水、台风等自然灾害；战争、武装冲突；政府行为（征收征用）；传染病疫情。

### 处理原则
- 发生后立即通知对方
- 提供证明文件
- 协商调整合同
- 损失各自承担原则
