# /合规性检查 -- 石油行业合同合规审查

> 如遇到不熟悉的占位符或需检查已连接工具，参见 [CONNECTORS.md](../../CONNECTORS.md)。

审查合同条款是否符合石油行业监管要求，输出合规风险清单和整改建议。

**重要提示**：本技能辅助合规审查，不构成法律意见。合规问题应由法务团队和合规部门联合确认。

**独立能力（无需连接器）**

- 石油行业7大合规领域逐项检查（安全生产、环境保护、矿产资源、劳动保护、保险、数据知识产权、数据安全网络安全）
- 乙方/甲方双立场合规重点适配
- 合规风险清单（合规/待整改/不合规三级标记）
- 具体整改建议（含条款修改措辞）
- 法律依据索引（对应法条+处罚条款）
- 引用 [石油行业合同知识库](../石油行业合同知识库/SKILL.md) 的合规要求

**增强能力（连接器加持）**

- ~~Notion -> 将合规检查报告发布到 Notion，便于团队整改跟踪

## 立场确认（每次调用必须执行）

**合规性检查前必须先确认我方立场，立场决定合规检查重点和整改建议方向：**

使用 AskUserQuestion 工具向用户确认：

- **乙方/服务提供方**：我方提供录井、信息化、检测、一体化、导向等服务（合规重点：安全生产合规（我方安全管理责任）、环境保护合规、数据与知识产权合规（IP争取归我方）、劳动保护合规、保险合规、网络安全合规）
- **甲方/委托方**：我方采购设备、租赁设备、委托外协服务（合规重点：质量标准合规（供应商须达标）、交付合规（供应商须按时）、违约条款合规（违约金须有力）、保险合规（供应商须有保险）、安全生产合规（外协方须持资质）、禁止转包合规）
- **平衡型**：双方合规风险均衡审查

**立场与合同类型的典型对应关系（仅供参考，最终以用户确认为准）：**

| 合同类型 | 常见立场 | 说明 |
|---------|---------|------|
| 地质录井 / 钻试修信息化 / 检测分析 / 一体化 / 导向 | 乙方 | 检查我方服务合规风险 |
| 采购设备/物资 | 甲方 | 检查供应商合规风险 |
| 设备(钻具)租赁 | 甲方（承租方） | 检查出租方合规风险 |
| 委托外协服务 | 甲方 | 检查外协方合规风险 |

**立场确认后，后续所有合规检查重点、整改建议方向均基于该立场执行。**

## 执行流程

### 第一步：识别合同类型与监管框架

根据合同类型确定需要检查的合规领域和适用法规：

| 合同类型 | 必查合规领域 |
|---------|------------|
| **地质录井** | 安全生产 + 环境保护 + 数据/知识产权 + 劳动保护 + 保险 |
| **钻试修现场信息化** | 安全生产 + 数据安全/网络安全 + 知识产权 + 个人信息保护 + 保险 |
| **试验检测与解释分析** | 知识产权 + 数据归属 + 质量标准 + 保险 |
| **地质工程一体化** | 安全生产 + 环境保护 + 数据/知识产权 + 劳动保护 + 保险 |
| **地质导向** | 安全生产 + 数据安全 + 知识产权 + 劳动保护 + 保险 |
| **采购设备/物资** | 质量标准 + 环境保护 + 安全生产（如涉及井场设备）+ 违约条款 |
| **设备/钻具租赁** | 安全生产 + 保险（出租方投保）+ 质量标准（完好率） |
| **委托外协服务** | 安全生产（外协方资质）+ 知识产权（归委托方）+ 禁止转包 + 违约条款 |
| **HSE安全协议** | 安全生产 + 环境保护 + 应急管理 + 保险 |

### 第二步：七大合规领域逐项检查

基于 [石油行业合同知识库](../石油行业合同知识库/SKILL.md) 的合规要求对照表，逐项检查：

---

**1. 安全生产合规（《安全生产法》+行业规定）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 安全责任条款 | 合同必须明确划分安全生产责任 | 安全事故责任争议、行政处罚 | 《安全生产法》第5/21/25条 |
| 安全资质要求 | 承包方须持有安全生产许可证 | 合同可能无效、面临处罚 | 《安全生产法》第20条 |
| 安全培训条款 | 应约定安全培训频次和内容 | 安全事故中培训不足加重责任 | 《安全生产法》第28条 |
| 危险作业管理 | 应约定井场危险作业审批流程 | 违法作业面临停产整顿 | 《安全生产法》第40条 |
| 事故报告义务 | 应约定事故报告时限和流程 | 隐瞒事故面临行政处罚甚至刑事 | 《安全生产法》第83条 |
| 应急预案 | 应约定应急预案编制和演练要求 | 无预案面临处罚 | 《安全生产法》第81条 |

---

**2. 环境保护合规（《环境保护法》+《石油天然气开采污染防治规定》）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 环保责任条款 | 合同必须约定环境保护责任 | 环保事故责任争议 | 《环境保护法》第6/42条 |
| 污染防治措施 | 应约定钻井废液/泥浆处理方案 | 环保处罚、停产 | 《石油天然气开采污染防治规定》 |
| 环境恢复义务 | 应约定完井后环境恢复责任 | 生态修复费用争议 | 《环境保护法》第39条 |
| 环评要求 | 应确认环评审批是否完成 | 未批先建面临处罚 | 《环境影响评价法》第25条 |

---

**3. 矿产资源合规（《矿产资源法》+行业规定）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 探矿权/采矿权 | 应确认井区探矿权/采矿权状态 | 无权施工合同可能无效 | 《矿产资源法》第3条 |
| 地质资料汇交 | 应约定地质资料汇交义务 | 不汇交面临处罚 | 《地质资料管理条例》 |
| 井区范围确认 | 合同应明确井区/区块范围 | 越界开采面临处罚 | 《矿产资源法》第19条 |

---

**4. 劳动保护合规（《劳动法》+《劳动合同法》）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 驻井人员劳动关系 | 应明确驻井人员劳动关系归属 | 劳动争议、工伤赔偿争议 | 《劳动合同法》第7条 |
| 工伤保险 | 应约定工伤保险覆盖范围 | 工伤赔偿争议 | 《工伤保险条例》第62条 |
| 特殊工种保护 | 应约定高温/噪音/有毒环境保护措施 | 劳动监察处罚 | 《劳动法》第54条 |
| 工作时间 | 应约定驻井人员工作时间安排 | 超时工作面临劳动监察处罚 | 《劳动法》第36-41条 |

---

**5. 保险合规（《保险法》+行业惯例）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 雇主责任险 | 应约定雇主责任险最低保额≥100万/人 | 事故赔偿不足 | 《安全生产法》第51条 |
| 设备保险 | 应约定钻具/设备保险覆盖范围 | 设备损失无保障 | 行业惯例 |
| 第三者责任险 | 应约定井场第三者责任险 | 第三方损害赔偿争议 | 行业惯例 |
| 保险受益人 | 应明确保险受益人约定 | 赔偿金分配争议 | 《保险法》第18条 |

---

**6. 数据与知识产权合规（《著作权法》+行业规定）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 录井数据归属 | 应约定录井数据/地质资料归属 | 数据权属争议 | 《著作权法》第11条 |
| 地质数据保密 | 应约定地质数据保密等级和期限 | 数据泄露责任不明 | 《反不正当竞争法》第9条 |
| 技术成果归属 | 应约定钻井技术成果归属 | 知识产权纠纷 | 《民法典》第847-848条 |
| 数据汇交 | 应约定地质资料汇交义务 | 行政处罚 | 《地质资料管理条例》 |

---

**7. 数据安全与网络安全合规（《网络安全法》+《数据安全法》+《个保法》）**

| 检查项 | 合规要求 | 不合规后果 | 法律依据 |
|-------|---------|----------|---------|
| 网络安全等级保护 | 信息化系统应满足网络安全等级保护要求 | 行政处罚、系统被通报 | 《网络安全法》第21条 |
| 数据分类分级 | 应约定数据分类分级管理 | 数据泄露无分级响应机制 | 《数据安全法》第21条 |
| 数据处理者义务 | 我方作为受托数据处理者应履行安全义务 | 数据泄露面临处罚 | 《数据安全法》第27条 |
| 个人信息保护 | 如涉及员工/客户个人信息须合规处理 | 行政处罚、民事赔偿 | 《个保法》第13-27条 |
| 跨境数据传输 | 如井场数据涉及跨境传输须合规 | 行政处罚 | 《个保法》第38-43条 |
| 数据泄露通知 | 约定数据泄露通知时限和流程 | 隐瞒泄露面临加重处罚 | 《数据安全法》第29条 |

---

### 第三步：标记合规等级

**合规（绿色）**——条款完全符合监管要求，无需修改。

**待整改（黄色）**——条款基本框架存在但细节不满足合规要求。
必须输出：现有条款内容 + 不合规的具体点 + 整改建议措辞 + 法律依据。

**不合规（红色）**——条款缺失或严重违反监管要求。
必须输出：合规要求描述 + 不合规的具体风险 + 行政处罚/法律后果 + 整改建议措辞 + 法律依据。

## 质量标准

- 每项合规检查必须引用具体法律条文和处罚条款
- 整改建议必须提供具体条款修改措辞，非笼统方向性建议
- 合规等级标记必须有明确理由和法律依据
- 不得遗漏石油行业特有的合规检查项（安全生产、环保、矿产资源等）
- 安全生产法合规检查必须覆盖所有关键条款
- 行政处罚后果必须具体（罚款金额、停产整顿等）
- 环保合规必须考虑钻井作业特有污染类型

## 关联技能

- **审查合同** -- 对合同做完整的风险审查（合规检查是审查的一个维度）
- **法条速查** -- 深入了解特定合规要求的法条细节
- **条款经济影响评估** -- 量化评估不合规条款可能带来的行政处罚经济损失
- **起草合同** -- 根据合规要求起草或修改合同条款
- **石油行业合同知识库** -- 查阅行业合规要求和惯例参数
