# 石油行业合同知识库（地质录井服务公司定制版）

本知识库为其他技能提供双视角专业参考信息。**立场由各技能确认步骤动态决定**——乙方场景和甲方场景各有对应的惯例参数和防范要点。

## 公司业务线与合同类型分布（双立场）

我方在不同业务场景中承担不同立场角色：

| 业务线/场景 | 主要合同类型 | 我方角色 | 核心关注点 |
|-------|------------|---------|-----------|
| **地质录井** | 录井技术服务合同 | 乙方（录井服务商） | 数据成果权益保护、驻井人员管理权、验收标准量化 |
| **钻试修现场信息化** | 信息化服务合同 | 乙方（信息化服务商） | 系统运维责任边界、数据安全与归属、软件知识产权 |
| **试验检测与解释分析** | 检测分析服务合同 | 乙方（检测服务商） | 检测结论免责、原始数据保留、报告用途限制 |
| **地质工程一体化** | 综合技术服务合同 | 乙方（一体化服务商） | 多专业协同责任划分、知识产权（地质模型/算法） |
| **地质导向** | 地质导向服务合同 | 乙方（导向服务商） | 导向决策责任、实时数据传输、轨迹精度验收 |
| **采购设备/物资** | 采购/买卖合同 | **甲方（采购方）** | 供应商质量保障、验收严格把控、违约惩罚有力 |
| **设备/钻具租赁** | 租赁合同 | **甲方（承租方）** | 租金封顶、正常磨损保护、提前退租合理条件 |
| **委托外协服务** | 外协服务合同 | **甲方（委托方）** | 外协方服务质量约束、知识产权归委托方、违约有力 |

## 核心立场原则（动态适用）

立场由各技能确认步骤确定后，适用以下对应原则：

**乙方/服务提供方立场时适用：**

1. 知识产权归属争取——解释成果、地质模型、解释算法争取归我方
2. 验收标准量化——拒绝"甲方认可"
3. 驻井人员自主权——甲方仅有安全监管权
4. 甲方配合义务——甲方须提供食宿/数据接口等
5. 服务范围锁定——超范围另行付费
6. 不可抗力对等——天气停工期间我方获基本工资+折旧

**甲方/委托方立场时适用：**

1. 履约保障有力——供应商/外协方违约金充足、交付时限约束
2. 验收标准严格——量化验收+默示验收+供应商举证责任
3. 知识产权归委托方——外协成果含算法归甲方
4. 质量保障——质保期明确、质保金作为约束手段
5. 退出机制完善——提前退租/终止合同条件合理
6. 禁止转包——外协方不得擅自转包

## 业务线一：地质录井合同知识库

### 起草要点与行业惯例参数

| 条款 | 起草要点（乙方立场） | 行业基准参数 |
|-----|---------|------------|
| 计费方式 | 按井计费（含驻井费+解释费）或按进尺计费 | 按井：5-50万/井（视井深和录井项目）；按进尺：50-200元/米 |
| 付款节点 | 预付比例争取30%-40%，质保金压至5% | 预付30%-40% + 完工结算60%-70% + 质保金5%-10%（力争5%） |
| 驻井人员管理 | 我方行使劳动管理权，甲方仅有安全监管权 | 每井2-4人（操作员+解释员）、24小时连续作业需轮班 |
| 数据成果归属 | **原始数据归甲方，解释成果/解释算法归我方** | 约定："原始采集数据归甲方，解释成果、解释方法、分析模型归乙方" |
| 服务质量验收 | 量化指标，拒绝主观验收 | 覆盖率≥95%、解释符合率≥85%、时效性（完井后X日内提交报告） |
| 驻井人员伤亡 | 我方承担工伤，但甲方须提供安全作业条件 | 雇主责任险≥100万/人，甲方承担因井场安全隐患导致的事故 |
| 保密条款 | 地质数据保密，但保留解释方法商业秘密 | 一般地质数据终止后3-5年、储量信息永久保密、**解释算法和模型永久保密** |
| 甲方配合义务 | 甲方须提供食宿、交通、通讯 | 甲方提供井场食宿条件、交通安排、通讯设施、安全作业环境 |
| 不可抗力停工 | 甲方原因/天气停工：我方获基本工资+设备折旧 | 人员基本工资约300-500元/人/天、设备折旧另计 |

### 关键法条映射

| 法条 | 适用条款 | 说明（乙方视角） |
|-----|---------|------|
| 《民法典》第859条 | 知识产权条款 | 委托开发专利申请权归开发方——我方解释算法应争取归我方 |
| 《民法典》第847条 | 技术成果归属 | 职务技术成果归单位——我方解释成果属职务成果 |
| 《民法典》第577-585条 | 违约责任 | 违约金量化校验 |
| 《安全生产法》第5条 | HSE条款 | 安全生产责任——我方负责安全管理、甲方负责安全监管 |
| 《安全生产法》第20条 | 安全资质 | 安全生产许可证——我方须持有 |
| 《安全生产法》第28条 | 安全培训 | 入场培训——甲方提供井场特定风险培训 |
| 《安全生产法》第51条 | 保险条款 | 雇主责任险——我方购买 |

### 高频争议防范（乙方视角）

| 争议类型 | 常见甲方条款陷阱 | 乙方防范条款设计 |
|---------|---------|------------|
| 数据成果归属 | "所有数据和成果归甲方所有" | 分层约定：原始数据归甲方，解释成果和算法归乙方，甲方获得使用权 |
| 验收标准模糊 | "甲方认可即视为验收合格" | 约定量化指标+客观验收标准，甲方超期未答复视为验收合格（默示验收） |
| 驻井人员管理 | "驻井人员须服从甲方现场管理" | 明约定驻井人员服从我方劳动管理，甲方仅有安全监管和工作协调权 |
| 质保金过高 | 质保金10%-15% | 质保金争取5%，质保期缩短（3-6月而非1-2年，录井服务无长期质保需求） |
| 停工损失全扣 | 停工期间不付任何费用 | 区分停工原因：甲方/天气停工付基本工资+设备折旧，乙方原因停工我方自负 |
| 超范围服务 | 甲方额外要求录井项目但未加价 | 约定服务范围清单，超出项目另行计费 |

## 业务线二：钻试修现场信息化服务合同知识库

## 业务线三：试验检测与解释分析合同知识库

### 起草要点与行业惯例参数

| 条款 | 起草要点（乙方立场） | 行业基准参数 |
|-----|---------|------------|
| 检测范围 | 明确约定检测项目、方法标准、样品数量 | 检测项目清单+国标/行标编号 |
| 计费方式 | 按检测项目计费或按批次计费 | 单项检测0.5-5万、批量检测5-50万 |
| 检测结论 | 约定检测结论仅对送检样品负责，不扩展至全部地质结论 | "检测结论仅对送检样品有效，不代表对整井/整区块的评价" |
| 原始数据 | 约定检测原始数据保留期限和查阅方式 | 原始数据保留≥6个月，甲方可在保留期内查阅 |
| 报告用途 | 约定检测报告仅限约定用途 | "检测报告仅供本合同约定用途使用，乙方不对超出约定用途的后果承担责任" |
| 解释分析 | 区分检测数据与解释分析，分别计费和约定归属 | 检测原始数据归甲方、解释分析成果和解释方法归乙方 |
| 付款节点 | 预付+出报告结算 | 预付30%-50% + 检测完成出报告后50%-70% |

| 条款 | 起草要点（乙方立场） | 行业基准参数 |

## 石油行业合同常见违约金基准（乙方视角）

## 知识库使用说明

本知识库供以下技能引用（立场由各技能确认步骤动态决定）：
- **审查合同** — 审查条款时引用对应立场防范要点和行业惯例参数
- **起草合同** — 起草条款时引用对应立场起草要点和行业基准值
- **合规性检查** — 检查合规性时引用法规要求和处罚条款
- **条款经济影响评估** — 计算经济影响时引用对应视角违约金基准和事故损失估算
- **合同对比** — 对比条款差异时引用对应立场行业惯例作为对照基准
- **谈判备忘整理** — 整理谈判成果时引用对应立场底线和行业惯例参考值
- **NDA快筛** — 确定保密信息关注重点时引用对应立场保密等级和行业提示
- **法条速查** — 提供实务解读时引用对应立场裁判倾向和操作建议
- **合同台账提醒** — 确定提醒优先级时引用对应立场关注节点

各技能引用方式：参见 [石油行业合同知识库](../石油行业合同知识库/SKILL.md) 的[具体章节名]。乙方场景引用乙方视角章节，甲方场景引用甲方视角章节。
