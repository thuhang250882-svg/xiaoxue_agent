# 招标技术要求编制指南

## 一、录井技术服务技术要求

### 1.1 服务范围
- 井号、井别（探井/评价井/开发井）
- 井型（直井/定向井/水平井）
- 设计井深及实际服务井段
- 服务周期（预计开始日期、预计工期）
- 服务地点（井场位置）

### 1.2 设备配置要求

#### 综合录井仪
| 参数项 | 要求 |
|--------|------|
| 仪器型号 | 具备CNAS认证或同等资质 |
| 传感器类型 | 气体分析仪（FID）、密度计、温度计、压力计、流量计等 |
| 气体检测 | C1-C5+全烃检测，分辨率不低于1ppm |
| 数据采集 | 采样间隔不大于0.5m |
| 数据存储 | 连续采集，自动备份 |
| 实时传输 | 支持实时数据远传 |

#### 地化录井仪（如需）
| 参数项 | 要求 |
|--------|------|
| 热解温度范围 | 90-600℃ |
| 检测参数 | S0, S1, S2, S3, Tmax |
| 分析精度 | 相对误差≤5% |

### 1.3 人员要求
| 岗位 | 数量 | 资质要求 |
|------|------|---------|
| 录井队长 | 1人 | 中级以上录井工资格，5年以上录井经验 |
| 地质录井员 | 2人 | 初级以上录井工资格，2年以上经验 |
| 气测录井员 | 2人 | 初级以上录井工资格 |
| 仪器操作员 | 2人 | 具备仪器操作培训证书 |

### 1.4 技术标准
- SY/T 5784-2018 《石油天然气钻探地质录井规程》
- SY/T 6038-2018 《探井地质录井资料录井规范》
- SY/T 5599-2018 《气测录井资料解释规范》
- SY/T 5788.1-2008 《油气探井完井地质总结报告编写规范》

### 1.5 资料提交要求
| 资料类型 | 提交时间 | 格式要求 |
|---------|---------|---------|
| 录井日报 | 每日上午8:00 | 电子+纸质 |
| 录井月报 | 每月末 | 电子+纸质 |
| 异常报告 | 发现异常后2小时 | 电子 |
| 完井总结报告 | 完井后15个工作日 | 电子+纸质，5份 |

### 1.6 质量指标
| 指标 | 合格标准 |
|------|---------|
| 录井符合率 | ≥95% |
| 气测异常发现率 | ≥90% |
| 资料优良率 | ≥85% |
| 岩屑捞取间距符合率 | 100% |

## 二、钻井工程技术要求

### 2.1 井身结构
- 套管程序：表层套管、技术套管、油层套管
- 井径系列：按设计执行
- 井斜控制：直井井斜≤3°，定向井按设计轨迹

### 2.2 钻井液
- 体系选择：按地层特性选择
- 性能参数：密度、粘度、失水、含砂等
- 维护要求：定时检测，及时调整

### 2.3 井控要求
- 井控等级：按SY/T 6426-2018执行
- 防喷器配置：按井控等级配备
- 井控演练：开钻前组织井控演练

### 2.4 固井质量
- 水泥浆体系：按地层条件选择
- 质量标准：声幅测井合格率≥90%
- 返高要求：水泥返高达到设计要求

## 三、设备物资技术要求

### 3.1 钻头
- 型号、规格、IADC编码
- 适应地层条件
- 预期进尺和寿命

### 3.2 套管
- 钢级、壁厚、螺纹类型
- 强度校核要求
- 检验标准：API 5CT

### 3.3 钻井液材料
- 材料名称、规格、等级
- 检验标准
- 储存和保管要求

## 四、技术要求编写注意事项

1. **不得指定品牌**：技术参数应采用通用指标，可标注"或同等性能产品"
2. **参数可量化**：所有技术要求应有明确的量化指标
3. **标准现行有效**：引用标准应注明版本年份
4. **无歧视性条款**：资质条件不得排斥潜在投标人
5. **完整性**：技术要求应覆盖全部服务范围和验收条件
