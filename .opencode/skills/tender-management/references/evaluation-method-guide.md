# 评标办法设计指南

## 一、评标方法选择

### 1.1 选择原则

| 项目特点 | 推荐方法 | 理由 |
|---------|---------|------|
| 技术复杂、方案差异大 | 综合评估法 | 技术方案是关键因素 |
| 标准化设备/材料 | 经评审最低投标价法 | 产品标准化，价格主导 |
| 技术服务类 | 综合评估法（技术分权重高） | 服务质量是核心 |
| 通用工程 | 综合评估法（价格分适中） | 平衡技术与价格 |

### 1.2 方法对比

| 对比项 | 综合评估法 | 经评审最低投标价法 |
|--------|-----------|-----------------|
| 适用场景 | 复杂项目 | 标准化项目 |
| 技术评分 | 有 | 仅评审是否满足要求 |
| 价格评分 | 按公式计算 | 最低价优先 |
| 评审深度 | 全面评审 | 符合性评审 |
| 防低价抢标 | 较好 | 需设置成本预警线 |

### 2.2 价格分计算公式

#### 常用公式1（基准价法）
```
基准价 = 所有有效投标报价的算术平均值
或 基准价 = 招标控制价 × [权重] + 有效投标报价平均值 × [权重]

价格分 = 满分 - |投标报价 - 基准价| / 基准价 × 100 × n
（n为扣分系数，一般取1-2）
```

#### 常用公式2（线性插值法）
```
最低有效报价得满分
最高有效报价得最低分（一般0-60%满分）
中间报价按线性插值计算

价格分 = 满分 × (1 - (投标报价 - 最低报价) / (最高报价 - 最低报价) × (1 - 最低得分率))
```

### 2.3 否决投标条件（常见）

- 投标文件未按规定签字盖章
- 投标报价超过招标控制价
- 投标报价低于成本且无法说明合理性
- 投标人资格不满足要求
- 投标文件弄虚作假
- 投标有效期不足
- 联合体投标未提供联合协议
- 不接受招标文件实质性条款

## 三、评标委员会

### 3.1 组成要求
- 成员人数：5人以上单数
- 技术/经济专家：不少于成员总数2/3
- 招标人代表：不超过1/3
- 专家来源：从政府或企业评标专家库随机抽取

### 3.2 评标程序
1. 初步评审：符合性检查（形式、资格、响应性）
2. 详细评审：按评标办法逐项打分
3. 澄清答疑：必要时要求投标人澄清
4. 推荐中标候选人：按总分排序，推荐1-3名
5. 编写评标报告
