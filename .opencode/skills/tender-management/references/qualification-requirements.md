# 投标人资格条件设置指南

## 一、通用资格条件

### 1.1 基本资格要求
- 具有独立承担民事责任能力的法人或其他组织
- 具有良好的商业信誉
- 具有履行合同所必需的设备和专业技术能力
- 近三年内无重大违法违规记录
- 近三年内无重大安全责任事故
- 未被列入失信被执行人名单

### 1.2 财务要求
| 合同金额 | 注册资本要求 | 年营业收入要求 |
|---------|------------|-------------|
| 100万以下 | ≥100万 | ≥500万 |
| 100-500万 | ≥500万 | ≥2000万 |
| 500-2000万 | ≥2000万 | ≥1亿 |
| 2000万以上 | ≥5000万 | ≥3亿 |

## 二、专项资质要求

### 2.1 录井技术服务

| 资质项 | 要求 |
|--------|------|
| 录井资质 | 具有石油天然气录井服务资质 |
| 安全生产许可证 | 持有有效安全生产许可证 |
| HSE认证 | 通过HSE管理体系认证（ISO 45001或同等） |
| 质量认证 | 通过ISO 9001质量管理体系认证 |
| 设备认证 | 录井仪器具有计量认证或CNAS认证 |

### 2.2 钻井工程

| 资质项 | 要求 |
|--------|------|
| 钻井资质 | 具有石油天然气钻井服务资质 |
| 安全生产许可证 | 持有有效安全生产许可证 |
| 井控资质 | 具有井控设备操作资质 |
| 环保许可 | 具有环境保护相关许可 |

### 2.3 设备物资采购

| 资质项 | 要求 |
|--------|------|
| 生产/代理资质 | 制造商或授权代理商 |
| 产品认证 | API认证、CCC认证等（按产品类型） |
| 检验报告 | 第三方检验机构出具的质量检验报告 |
| 代理授权 | 代理商需提供制造商授权书 |

## 三、业绩要求设置原则

### 3.1 合理性原则
- 业绩要求不得高于项目实际需要
- 不得设置特定地区、特定客户的业绩要求
- 业绩金额不得高于招标项目金额
- 近3-5年业绩为合理期限

### 3.2 录井服务业绩参考

| 项目规模 | 业绩要求 |
|---------|---------|
| 单井录井 | 近3年完成3口以上类似录井服务 |
| 多井批量录井 | 近3年完成10口以上录井服务，含2口以上水平井 |
| 特殊录井（地化等） | 近3年完成2口以上同类录井服务 |

### 3.3 钻井工程业绩参考

| 项目规模 | 业绩要求 |
|---------|---------|
| 浅井/中深井 | 近3年完成5口以上同类井 |
| 深井/超深井 | 近3年完成3口以上深井（≥4000m） |
| 水平井 | 近3年完成3口以上水平井 |

## 四、人员资质要求

### 4.1 录井服务人员

| 岗位 | 资质要求 | 经验要求 |
|------|---------|---------|
| 录井队长 | 中级及以上录井工资格证 | 5年以上录井经验，3年以上队长经历 |
| 地质录井员 | 初级及以上录井工资格证 | 2年以上录井经验 |
| 气测录井员 | 初级及以上录井工资格证 | 1年以上气测录井经验 |
| 仪器操作员 | 仪器操作培训证书 | 2年以上仪器操作经验 |

### 4.2 钻井工程人员

| 岗位 | 资质要求 | 经验要求 |
|------|---------|---------|
| 平台经理/队长 | 司钻证、井控证 | 8年以上钻井经验 |
| 司钻 | 司钻证、井控证 | 3年以上司钻经验 |
| 泥浆工 | 泥浆工资格证 | 2年以上经验 |
| 井控员 | 井控操作证 | 3年以上井控经验 |

## 五、禁止性规定

### 以下资格条件设置属于不合理限制
- 限定特定行政区域或特定行业的业绩
- 限定特定品牌、商标或专利
- 要求注册年限超过3年
- 业绩金额要求超过招标项目金额
- 限定特定规模的业绩（如要求特定油田业绩）
- 设置与项目无关的资质条件
