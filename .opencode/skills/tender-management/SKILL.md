# 招标文件管理助手

本技能用于石油钻探行业招标文件的编写、审核和评标管理。

## 适用招标类型

1. **录井技术服务招标** — 综合录井、气测录井、地化录井等
2. **钻井工程招标** — 钻井总承包、定向井、固井等
3. **设备物资采购招标** — 钻头、套管、钻井液材料、录井仪器等
4. **技术服务招标** — 地质设计、钻井设计、技术研究等
5. **工程维修招标** — 井场建设、道路维修等

## 招标文件组成结构

```
招标文件
├── 第一卷：招标公告/投标邀请书
├── 第二卷：投标人须知
├── 第三卷：评标办法
├── 第四卷：合同条款及格式
├── 第五卷：技术标准和要求
├── 第六卷：投标文件格式
└── 图纸/附件
```

## 招标文件编写流程

### 第一步：确定招标方式和组织形式

| 招标方式 | 适用条件 | 审批权限 |
|---------|---------|---------|
| 公开招标 | 国家规定必须招标的项目 | 按金额分级审批 |
| 邀请招标 | 特殊技术要求、潜在投标人有限 | 需审批 |
| 竞争性谈判 | 技术复杂、工期紧 | 需审批 |
| 单一来源 | 唯一供应商 | 严格审批 |
| 询价 | 金额小、规格标准 | 简化审批 |

### 第二步：编制技术要求

按 `references/technical-requirements-guide.md` 编制技术部分：

#### 录井技术服务技术要求要点
- **服务范围**：井号、井型、设计井深、服务周期
- **设备配置**：综合录井仪型号、传感器配置、气体分析仪
- **人员要求**：录井队长、操作员资质和数量
- **技术标准**：执行SY/T 5784等行标
- **资料要求**：日报、月报、异常报告、完井总结
- **质量要求**：录井符合率、异常发现率、资料优良率

#### 钻井工程技术要求要点
- **井身结构**：套管程序、井径系列
- **钻井液**：体系选择、性能参数
- **固井**：水泥浆体系、质量标准
- **井控**：井控等级、设备配置
- **完井**：完井方式、射孔要求

### 第三步：设计评标办法

按 `references/evaluation-method-guide.md` 设计评标办法：

#### 常用评标方法

| 方法 | 适用场景 | 特点 |
|------|---------|------|
| 综合评估法 | 技术复杂项目 | 技术分+商务分+价格分 |
| 经评审的最低投标价法 | 标准化设备采购 | 以价格为主 |
| 竞分法 | 服务类招标 | 价格+技术双因素 |

#### 综合评估法分值分配（录井服务参考）

| 评审项 | 分值 | 子项 |
|--------|------|------|
| 投标报价 | 30-40分 | 报价基准价偏差、报价合理性 |
| 技术方案 | 30-40分 | 施工方案、技术措施、设备配置 |
| 业绩资质 | 10-15分 | 类似业绩、资质等级、人员资质 |
| 服务承诺 | 5-10分 | 响应时间、售后服务、应急保障 |
| HSE管理 | 5-10分 | HSE体系、安全业绩、环保措施 |

### 第四步：设置资质条件

按 `references/qualification-requirements.md` 设置投标人资格条件。

### 第五步：编写招标文件

按 `references/tender-template-structure.md` 的结构逐章编写。

## 招标文件审核流程

### 第一卷：招标公告审核

- [ ] 项目名称准确
- [ ] 招标范围描述清晰
- [ ] 资金来源说明
- [ ] 投标人资格条件明确
- [ ] 投标截止时间合理
- [ ] 获取文件方式和费用

### 第二卷：投标人须知审核

- [ ] 总则说明完整
- [ ] 招标文件说明（构成、澄清、修改）
- [ ] 投标文件编制要求（格式、语言、份数）
- [ ] 投标文件递交要求（密封、标记、截止时间）
- [ ] 开标程序和规则
- [ ] 评标程序和规则
- [ ] 合同授予标准
- [ ] 纪律和监督

### 第三卷：评标办法审核

- [ ] 评标方法选择合理
- [ ] 评审因素和分值分配合理
- [ ] 否决投标条件明确
- [ ] 评标委员会组成
- [ ] 评标程序完整

### 第四卷：合同条款审核

- [ ] 合同条款与招标文件一致
- [ ] 引用合同模板与项目类型匹配
- [ ] 特殊条款约定合理
- [ ] 合同价格形式明确

### 第五卷：技术要求审核

- [ ] 技术标准引用正确且现行有效
- [ ] 技术参数完整且可量化
- [ ] 质量标准和验收标准明确
- [ ] 无排他性条款（不指向特定品牌）
- [ ] HSE要求完整

### 第六卷：投标文件格式审核

- [ ] 格式模板完整
- [ ] 填写说明清晰
- [ ] 签章要求明确

## 注意事项

- 招标文件编制应符合《招标投标法》及实施条例
- 技术要求不得指定特定品牌或供应商
- 资质条件不得设置不合理限制
- 评标办法应与项目特点匹配
- 合同条款应与中标后实际执行的合同一致
