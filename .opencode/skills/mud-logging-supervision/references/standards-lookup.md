# 监督检查标准条款速查

## 目标

把现场检查发现的口语化问题，快速定位到已登记标准的具体条款，并生成可直接写入检查记录的规范性描述。只引用 `knowledge/standards/` 中已登记的现行标准，不凭记忆编造。

## 工作流程

1. **理解问题**：从用户描述中提取关键要素——对象（设备/传感器/资料/流程）、行为（安装/标定/监控/验收）、偏差（位置不对/超期/缺失/记录不全）。要素不全时先向用户确认，不做猜测。
2. **定位标准**：检索 `knowledge/standards/INDEX.md`，按适用范围筛出候选标准；优先选状态为「现行」的标准，涉及多标准时全部列出并注明主次。
3. **定位条款**：在候选标准的 `clauses.md` 条款卡中按关键词检索具体条款；条款卡未覆盖时，提示用户该标准尚未提取条款卡，并建议人工查阅 `original.pdf`。
4. **比对案例**：检索 `knowledge/inspection_cases/INDEX.md`，如有同类历史案例，附上案例编号与当时的整改要求作参考。
5. **输出三段式结果**（见下）。

## 输出格式

```
【问题归纳】<一句话客观归纳，不带定性结论>
【违反条款】<标准号> 第X.X条（第X页）：
> 条款原文摘录
【规范性描述】（可直接用于检查记录/整改通知的表述）
  经查，<单位/井号> 存在 <问题客观描述>，不符合 <标准号> 第X.X条关于 <条款要点> 的要求。
【整改建议】<可执行的整改要求 + 建议完成时限>
【参考案例】<案例编号，如无则写"无同类案例">
```

## 查询纪律

- 条款引用必须来自条款卡文件原文，逐字摘录，标注标准号、条款号、页码；禁止凭记忆生成条款内容。
- 检索不到依据时明确回复"未在已登记标准中找到依据"，列出建议核实的标准方向，由人工确认，不得硬凑条款。
- 已作废标准只在用户明确要求追溯时引用，并标注"已作废，被 XXXX 替代"。
- 生成的规范性描述是初稿，最终表述由检查人员确认后方可写入正式记录。
