# 现场照片对照检查

## 目标

对监督现场拍摄的照片做"看图说话"：识别画面中的设备、设施、作业状态，对照已登记标准和检查清单找出不规范之处，输出结构化的问题清单，供检查人员现场核对确认。

## 输入

1. 一张或多张现场照片（必需）。
2. 场景说明（建议提供）：井号/场所、拍摄对象（如"综合录井仪传感器安装""节流管汇"）、检查背景（日常巡检/专项检查/季节检查）。未提供时先询问，避免识别方向错误。

## 工作流程

1. **识别画面要素**：逐项列出照片中可辨认的设备、仪表、管线、标识、人员行为与作业环境；对辨认不清的要素标注"疑似"，不确定的不列入问题。
2. **确定检查依据**：根据场景检索 `knowledge/standards/INDEX.md` 与对应条款卡，确定适用的标准条款；有专项检查清单时一并对照。
3. **逐条比对**：将画面要素与条款要求逐项比对，找出偏差。只依据照片可见信息判断，不得推测照片外的情况（如"可能未标定"——照片无法证明的，只能提示"建议现场核查标定记录"）。
4. **输出问题清单**：每条问题按四要素输出（见下），按严重程度排序：井控安全类 > 设备功能失效类 > 安装规范类 > 标识记录类。
5. **给出核查提示**：对照片无法证实但值得现场确认的项目，单列"建议现场核查项"。

## 输出格式

每条问题：

```
问题N：<一句话概括>
① 问题位置：<照片中的具体位置，如"画面左侧司钻房外墙传感器支架">
② 具体表现：<照片可见的客观偏差>
③ 违反条款：<标准号 第X.X条；条款卡未覆盖时写"待核实"并给出核实方向>
④ 原因与整改建议：<常见原因分析 + 整改要求>
```

结尾附：

```
【建议现场核查项】<照片无法证实、需现场确认的事项>
【确认声明】以上识别结果基于照片画面，须由检查人员现场复核后确认。
```

## 判断纪律

- 照片模糊、遮挡、角度受限时，对应项目标注"无法判定"，不得脑补画面内容。
- 违反条款必须来自已登记标准的条款卡；查不到时写"待核实"，不得编造条款号。
- 不针对人员外貌、身份做评价，只对设备状态、作业行为与记录做判断。
- 输出是辅助判断初稿，所有问题须经检查人员现场确认方可计入检查结果。
