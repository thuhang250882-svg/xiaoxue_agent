# Word 排版格式规则（全局生效）

来源：《上报文字材料排版格式要求.docx》（人事组织科 2021年11月3日），原件备份于 `configs/templates/上报文字材料排版格式要求.docx` 与用户桌面。代码实现：`document_engine/templates/company_reporting_style.ts`（`company_reporting_default`）。

## 适用判定（先判断，再生成）

1. **智能体自己生成的 Word**（无原文档参照）→ 一律使用 `company_reporting_default` 格式导出，不得使用其他版式。
2. **任务中用户上传/指定了原文档** → 结果文件**沿用原文档自身格式**：克隆其字体、字号、行距、页边距、标题层级样式，不得改排为公司上报格式。修改类任务（office_document_revise）在原文件副本上操作，天然满足此条。
3. 用户在任务中明确提出特殊版式要求 → 以用户要求为准，覆盖默认规则，交付时说明所用格式。

## company_reporting_default 规范参数

| 元素 | 字体 | 字号 | 加粗 |
|---|---|---|---|
| 文章标题 | 方正小标宋简体 | 二号（22pt） | 否 |
| 一级标题（一、） | 方正黑体简体 | 三号（16pt） | 否 |
| 二级标题（（一）） | 方正楷体简体 | 三号（16pt） | 否 |
| 三级标题（1.） | 方正仿宋简体 | 三号（16pt） | **是** |
| 四级标题（（1）） | 方正仿宋简体 | 三号（16pt） | 否 |
| 正文 | 方正仿宋简体 | 三号（16pt） | 否 |
| 页码 | 方正仿宋简体 | 四号（14pt） | 否 |

## 版面参数

- 行距（固定值）：标题 1 行 → 全文 28 磅；标题 ≥2 行 → 标题 32 磅、正文 28 磅。
- 文字颜色：无特殊说明一律黑色。
- 页边距：上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm。
- 页码位置：外侧（奇数页右对齐、偶数页左对齐）。
- 纸张：A4；装订：骑马钉（仅纸质交付时提醒）。

## 生成与核对要点

- 通过 `office_document` 工具导出 DOCX 时自动应用全部参数，无需手工指定字体。
- 直接过 `document_engine` 或 `docx` 库手写生成时，中文字体必须同时设置 `eastAsia` 属性。
- 若办公电脑未安装方正字库，文件仍按规范字体名写入（装有字库的机器打开即正常显示），交付时提醒用户核对显示效果。
- 交付前自查：标题字体是否方正小标宋、正文是否三号仿宋、行距是否固定值、页边距四值是否正确。
