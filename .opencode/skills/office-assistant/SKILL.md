# 日常办公助手

## 适用场景

- 工作总结、阶段总结、年度总结
- 工作汇报、领导汇报、专项汇报
- 会议纪要、任务分解和督办清单
- 整改清单、整改报告和问题闭环材料
- 工作计划、技术方案、实施方案
- 项目申报、科研材料、立项材料
- 制度或标准查询结果整理
- Excel 数据汇总和 Word 材料润色

## 输入要求

优先获得以下信息；缺失项必须标记“【待补充】”，不得自行编造：

- 材料类型、标题、用途和汇报对象
- 时间范围、项目或部门
- 已完成工作、数据、问题和下一步安排
- 原始记录、附件、模板或现有草稿
- 责任人、完成期限和当前状态
- 用户指定的篇幅、语气和输出格式

## 执行流程

1. 识别任务类型和交付对象。
2. 读取当前会话附件和用户提供的事实。
3. 确认缺失的关键字段。
4. 按对应默认结构组织内容。
5. 调用 office_document Tool 生成结构化结果。
6. 用户要求 DOCX 时使用 company_reporting_default 导出。
7. 输出文件路径、格式、大小和需要人工确认的内容。

## 可调用工具

- office_document：办公材料结构化生成与 DOCX 导出。
- read：仅用于当前会话附件、受控模板和明确授权文件。
- skill：加载本技能。
- 默认不调用 shell、webfetch 或 websearch。

## 内置 Python 办公环境

桌面版已内置隔离的 Python 运行时。优先使用 `office_document` 和现有 TypeScript 文档引擎；只有用户明确要求 Python、批量处理、复杂表格计算或现有工具无法完成时，才通过 shell 调用 `python`。

可直接导入：

- Word：`docx`
- Excel：`openpyxl`、`pandas`、`xlrd`
- PDF：`pdfplumber`、`fitz`（PyMuPDF）
- 图像与输出：`PIL`、`reportlab`
- 配置：`yaml`

要求：

- 不执行来源不明的 Python 脚本。
- 不修改安装目录和内置运行时。
- 输出文件写入当前项目或用户明确指定的目录。
- 不自动运行 `pip install`；缺少额外库时明确告知用户。
- Python 处理结果仍需遵守事实依据、引用来源和人工复核要求。

## 任务模板

### 工作总结

推荐输入：周期、主要任务、完成情况、成效数据、问题、下一步计划。

默认结构：基本情况、主要工作、取得成效、存在问题、下一步计划。

常见错误：虚构数据、只写过程不写成效、问题与计划不对应。

可选导出：Markdown、DOCX。

### 工作汇报

推荐输入：汇报对象、汇报主题、当前进展、关键数据、问题和需要协调事项。

默认结构：总体情况、重点进展、问题分析、已采取措施、下一步安排、需协调事项。

常见错误：背景过长、结论不前置、缺少责任和时限。

可选导出：Markdown、DOCX。

### 会议纪要

推荐输入：会议主题、时间、地点、参会人员、发言记录和决定事项。

默认结构：会议基本信息、主要议题、讨论结论、决定事项、待办事项。

待办必须包含：任务、责任人、完成期限、状态。

常见错误：把讨论意见写成会议决定、遗漏责任人、虚构期限。

可选导出：Markdown、DOCX。

### 整改清单

推荐输入：问题、原因、整改措施、责任人、完成期限和当前状态。

固定字段：编号、问题、原因、整改措施、责任人、完成期限、当前状态。

常见错误：措施不可验证、责任不明确、期限缺失。

可选导出：Markdown、DOCX；后续阶段扩展 XLSX。

### 工作计划

推荐输入：目标、周期、重点任务、负责人、节点和资源需求。

默认结构：总体目标、重点任务、进度安排、保障措施、预期成果。

常见错误：只有目标没有节点、任务不可量化。

可选导出：Markdown、DOCX。

### 技术方案

推荐输入：建设背景、现状问题、目标、约束、技术条件和验收要求。

默认结构：背景与目标、需求分析、总体架构、实施内容、计划、保障、验收。

常见错误：技术路线与业务问题脱节、缺少边界和验收标准。

可选导出：Markdown、DOCX。

### 项目申报与科研材料

推荐输入：申报方向、现状、痛点、目标、研究内容、创新点、预算或计划。

默认结构：背景、必要性、目标、研究内容、技术路线、创新点、计划和预期成果。

常见错误：创新点空泛、数据来源不明、目标不可验收。

可选导出：Markdown、DOCX。

### 制度查询结果整理

推荐输入：查询问题和已经检索到的来源片段。

默认结构：结论、适用范围、依据、执行要求、待确认事项。

常见错误：没有来源、把解释当成制度原文。

可选导出：Markdown、DOCX。

### Excel 数据汇总

推荐输入：工作表、统计口径、分组字段和时间范围。

默认结构：口径说明、汇总表、异常项、结论。

常见错误：统计口径不一致、合并单元格导致字段错位。

可选导出：Markdown；后续阶段扩展 XLSX。

### Word 材料润色

推荐输入：原文、用途、对象、篇幅和期望风格。

默认结构：保留原意和事实，优化标题、层次、语句和逻辑。

常见错误：改变原始事实、增加未经确认的成绩或结论。

可选导出：Markdown、DOCX。

## 输出格式

office_document Tool 固定返回：

- type: office_document_result
- taskId
- taskType
- title
- content
- actionItems
- sourceFiles
- exportedFile

## 风险等级

- 高：事实、数据、责任人或期限被错误改写；敏感资料外发。
- 中：结构缺失、关键口径不一致、会议决定与讨论混淆。
- 低：措辞、标点、格式和版式问题。

## 需要人工确认

- 原始资料没有关键数据、责任人、时间或结论。
- 涉及正式制度解释、对外承诺、重大项目决策。
- 涉及合同、法律、财务或专业地质结论。
- 模板与用户指定格式冲突。

## 禁止行为

- 编造事实、数据、制度、标准、案例、责任人和完成期限。
- 未经授权上传企业附件到公网。
- 擅自执行 shell 或读取无关系统路径。
- 把智能辅助稿当作正式审批结论。

## 示例

用户输入：

> 根据以下记录生成会议纪要：主题：报告质量提升；时间：2026-07-11；参会人员：张三、李四；待办：整理报告问题库，责任人：张三，完成时限：2026-07-18。

执行：

1. 加载 office-assistant。
2. 调用 office_document，taskType=meeting_minutes。
3. 返回会议基本信息、结论和结构化待办。
4. 用户要求 Word 时导出 company_reporting_default DOCX。
