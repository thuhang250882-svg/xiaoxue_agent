# 项目立项文件包生成

## 概述

本技能为西部钻探地质研究院巴州分公司的信息化项目生成立项全套文件包。

公司每年通常立项 4-5 个信息化项目，项目类型高度模板化，同类型项目年复一年复用标准模板。每个项目需要提交一套标准立项文件（**立项标准模板6件套**）：

| 编号 | 文件名称 | 说明 | 适用项目类型 |
|------|----------|------|--------------|
| 01 | 项目立项申请表 | 一页纸审批表 | 全部 |
| 02 | 立项报告（可研/必要性论证） | 项目论证主体文件 | 全部 |
| 03 | 技术要求 | 技术规格和验收标准 | 全部 |
| 05 | 拟签合同文本 | 合同草案 | **跳过** — 由法务/合同部门负责 |
| 06 | 控制价格表 | 费用测算明细 | 全部 |
| 07 | 一单一采说明 | 单一来源采购说明 | 仅设备采购类 |

> 注意：05号合同文本不在本技能输出范围内，由合同管理部门独立起草。

### 常见项目类型

| 类型 | 典型场景 | 举例 |
|------|----------|------|
| 设备采购 | 井场信息化硬件设备批量采购 | 黑匣子、网桥、摄像头、交换机、服务器 |
| 人员服务 | 外包运维辅助人员年度服务 | 数据传输运维辅助人员、现场驻点工程师 |
| 技术服务 | 信息化低端辅助、通信集成 | 网络优化服务、系统集成调试、软件适配 |
| 设备租赁 | 年度设备租赁（含维保） | 井场监控设备租赁、网络设备租赁 |
| AI服务 | 2025年新增，云AI算力/模型服务 | 天翼云AI服务、智能录井分析平台 |

## 输入要求

使用本技能前，用户需提供以下信息（可分步补充）：

### 必填项

- **项目类型**：设备采购 / 人员服务 / 技术服务 / 设备租赁 / AI服务
- **项目名称**：例如"2025年度塔里木区域井场信息化设备采购"
- **项目背景**：为什么需要这个项目（业务痛点、上级要求、设备老化等）
- **采购内容**：具体要买什么/做什么，含数量
- **预算范围**：大致金额区间（万元）

### 可选项

- **供应商信息**：已有候选供应商时可填入（用于一单一采说明）
- **使用年度**：续做项目标注年份（如"2025年度"）
- **历史项目参考**：如往年同类项目，可提供上年项目名称以便沿用口径
- **上级文件依据**：如有红头文件、会议纪要等立项依据
- **交付时间要求**：项目期望完成节点

### 输入示例

```
项目类型：设备采购
项目名称：2025年度井场视频监控系统采购
背景：现有42个井场摄像头已达报废年限，故障率超30%，需批量更换
采购内容：高清球机摄像头50台、NVR存储20台、配套线缆辅材
预算：约180万元
供应商：海康威视（上年供应商，表现良好）
年度：2025
```

## 执行流程

### Step 1: 确认项目类型和所需文件

根据项目类型确定本次需要生成的文件清单：

| 项目类型 | 01申请表 | 02立项报告 | 03技术要求 | 06控制价格表 | 07一单一采说明 |
|----------|----------|------------|------------|--------------|----------------|
| 设备采购 | 是 | 是 | 是 | 是 | **是** |
| 人员服务 | 是 | 是 | 是 | 是 | 否 |
| 技术服务 | 是 | 是 | 是 | 是 | 否 |
| 设备租赁 | 是 | 是 | 是 | 是 | 否 |
| AI服务   | 是 | 是 | 是 | 是 | 否 |

**确认动作**：向用户展示所需文件列表，确认无误后进入生成阶段。

### Step 2: 生成立项申请表（01）

一页纸审批表，包含以下字段：

```
项目名称：
申请单位：西部钻探地质研究院巴州分公司
项目类型：设备采购/人员服务/技术服务/设备租赁/AI服务
项目预算：¥___万元
建设周期：____年__月 至 ____年__月
申请理由：（3-5句话概括必要性）
预期效果：（2-3句话概括效益）
部门负责人签字：
日期：
```

**写作要点**：申请理由要简洁有力，突出业务刚需和时效性，避免技术细节。

### Step 3: 生成立项报告（02）

立项报告是核心论证文件，结构如下：

#### 3.1 项目背景与必要性

- **业务现状**：描述当前业务/设备/系统的现状
- **问题分析**：列出具体痛点，用数据支撑（如"故障率30%"、"人员缺口5人"）
- **政策/管理要求**：引用上级文件、会议精神、考核指标（如有）
- **不做的后果**：说明如果不立项会造成什么影响

#### 3.2 项目目标

- 目标必须**可量化**，例如：
  - "更换50台摄像头，覆盖42个井场，监控在线率从65%提升至98%"
  - "配置8名运维辅助人员，保障全年数据传输可用率≥99.5%"
- 区分**建设目标**（交付物）和**效果目标**（业务改善）

#### 3.3 建设方案

- **技术路线**：采用的技术标准和架构
- **实施范围**：覆盖哪些井场/区域/部门
- **实施计划**：分阶段里程碑（甘特图或表格）
- **组织保障**：项目管理团队和责任分工

#### 3.4 投资测算

- 费用汇总表（详见Step 5控制价格表）
- 与上年同类项目对比（如适用）
- 资金来源说明

#### 3.5 效益分析

- **经济效益**：可量化的成本节约或效率提升
  - 示例："减少巡检人工成本约15万元/年"
  - 示例："设备故障响应时间从4小时缩短至30分钟"
- **管理效益**：安全合规、信息透明、决策支撑等
- **社会效益**：如节能减排、降低安全事故率

#### 3.6 风险分析

| 风险类型 | 风险描述 | 发生概率 | 影响程度 | 应对措施 |
|----------|----------|----------|----------|----------|
| 技术风险 | 例：新设备兼容性 | 中 | 中 | 提前做适配测试 |
| 进度风险 | 例：供货周期长 | 中 | 高 | 提前下单，备安全库存 |
| 预算风险 | 例：汇率波动 | 低 | 中 | 锁定合同价格 |

### Step 4: 生成技术要求（03）

技术要求文件按项目类型分别编写：

#### 设备采购类技术要求

```
一、设备清单与基本参数
   （表格：设备名称/型号要求/数量/关键参数）

二、硬件技术指标
   - 处理器/内存/存储要求
   - 环境适应性（温度、湿度、防爆等级——井场设备特别关注）
   - 接口与兼容性要求
   - 外观与安装要求

三、软件与固件要求
   - 操作系统/协议支持
   - 远程管理能力
   - 固件升级机制

四、验收标准
   - 到货检验：外观、数量、开箱测试
   - 功能测试：逐项功能验证
   - 性能测试：连续运行稳定性测试（72小时老化）
   - 文档验收：合格证、说明书、保修卡

五、质保与售后
   - 质保期限（一般≥2年）
   - 响应时间要求（4小时电话/24小时到场）
   - 备品备件要求
```

#### 人员服务类技术要求

```
一、服务内容与范围
   - 服务岗位设置
   - 各岗位职责描述

二、人员要求
   - 学历/专业要求
   - 工作经验要求（油气行业优先）
   - 技能证书要求（如电工证、网络工程师）
   - 身体条件（适应野外井场作业）

三、考核标准（KPI）
   | 考核项 | 达标标准 | 权重 | 考核方式 |
   |--------|----------|------|----------|
   | 出勤率 | ≥95% | 20% | 月度统计 |
   | 故障处理及时率 | ≥90% | 30% | 工单系统 |
   | 客户满意度 | ≥4.0/5.0 | 20% | 季度问卷 |

四、管理与纪律要求
   - 遵守HSE管理规范
   - 服从井场现场管理
   - 保密义务

五、交付物
   - 月度工作报告
   - 故障处理台账
   - 季度考核报告
```

#### 技术服务类技术要求

```
一、服务目标与范围
二、技术方案要求
三、服务等级协议（SLA）
四、交付物清单
五、验收标准
```

#### 设备租赁类技术要求

```
一、租赁设备清单与参数
二、租赁期限与交付方式
三、维护责任划分（出租方/承租方）
四、设备归还条件与标准
五、保险与损坏赔偿条款
```

#### AI服务类技术要求

```
一、算力资源要求
   - GPU型号与数量（如A100/V100）
   - 算力规格（TFLOPS）
   - 存储与带宽要求

二、模型与算法要求
   - 支持的模型类型
   - 精度要求
   - 训练/推理性能指标

三、数据安全要求
   - 数据不出域
   - 加密传输
   - 访问控制

四、平台功能要求
   - 可视化管理界面
   - API接口规范
   - 监控告警功能

五、服务支持与培训
```

### Step 5: 生成控制价格表（06）

控制价格表是费用测算的核心文件，必须做到**逐项明细、有据可查**：

#### 设备采购类

| 序号 | 设备名称 | 规格型号 | 单位 | 数量 | 单价(元) | 合计(元) | 价格来源 |
|------|----------|----------|------|------|----------|----------|----------|
| 1 | 高清球机摄像头 | DS-2DE4425IW | 台 | 50 | 3,200 | 160,000 | 上年合同价 |
| 2 | NVR存储 | DS-9632NI-K8 | 台 | 20 | 12,000 | 240,000 | 厂商报价 |
| ... | 辅材线缆 | 综合 | 批 | 1 | 80,000 | 80,000 | 市场询价 |
| | **合计** | | | | | **480,000** | |
| | 运输安装费(8%) | | | | | 38,400 | 行业惯例 |
| | 税金(13%) | | | | | 67,404 | 增值税 |
| | **项目总预算** | | | | | **585,804** | |

#### 人员服务类

| 序号 | 岗位名称 | 人数 | 月薪标准(元) | 月数 | 小计(元) | 说明 |
|------|----------|------|--------------|------|----------|------|
| 1 | 运维工程师 | 5 | 8,000 | 12 | 480,000 | 含社保公积金 |
| 2 | 现场技术员 | 3 | 6,500 | 12 | 234,000 | 含社保公积金 |
| | **人员费用合计** | 8 | | | **714,000** | |
| | 管理费(10%) | | | | 71,400 | |
| | 税金(6%) | | | | 47,124 | 服务业增值税 |
| | **项目总预算** | | | | **832,524** | |

**价格来源说明**：每个价格项必须标注来源，可选：
- 上年合同价（最可靠）
- 厂商正式报价
- 市场询价（至少2家对比）
- 行业指导价/定额标准
- [需确认] — 无法确认时标注

### Step 6: 生成一单一采说明（07，仅设备采购类）

当设备采购需要采用单一来源采购方式时，需编写说明文件：

```
一、采购内容概述
二、采用单一来源采购的原因
   （须符合以下条件之一）
   - 技术兼容性：需与现有系统兼容，只能选原厂商产品
   - 专利/专有技术：仅一家供应商拥有该技术
   - 紧急采购：时间紧迫，无法进行竞争性采购
   - 续购一致性：与上年保持一致，降低运维复杂度

三、唯一供应商说明
   - 供应商名称
   - 选择理由
   - 供应商资质

四、价格合理性说明
   - 与上年价格对比
   - 与市场同类产品价格对比
   - 价格谈判过程

五、审批意见栏
```

## 输出格式

### 文件组织

每个项目的输出按以下顺序组织，每个文件用明确标题分隔：

```
=====================================
文件01：项目立项申请表
=====================================
（内容）

=====================================
文件02：立项报告
=====================================
（内容）

=====================================
文件03：技术要求
=====================================
（内容）

=====================================
文件06：控制价格表
=====================================
（内容）

=====================================
文件07：一单一采说明（如适用）
=====================================
（内容）
```

### 格式规范

- **表格**：费用明细和技术参数一律使用表格，清晰直观
- **编号**：所有列表和章节使用层级编号（一、1.1、1.1.1）
- **单位**：金额统一使用"万元"或"元"，不混用；设备数量标注单位（台/套/批/个）
- **占位符**：需用户补充的信息使用 `[需确认：xxx]` 格式标注
- **日期**：使用中文日期格式"2025年X月"

## 质量标准

### 文件质量要求

1. **费用有据可查**：控制价格表中每一项费用都标注价格来源，不接受无来源的估价
2. **技术参数可验证**：技术要求中的参数应来自厂商公开资料或行业标准，不编造参数
3. **必要性论证有事实支撑**：立项报告中的现状描述和问题分析基于实际业务数据，不虚构痛点
4. **目标可量化**：每个项目目标都有具体数字，不使用"显著提升""大幅改善"等模糊表述
5. **风险有针对性**：风险分析针对本项目具体情况，不套用通用风险模板
6. **口径一致性**：各文件之间的项目名称、预算金额、数量完全一致，不能出现矛盾

### 续做项目特别要求

对于年度续做项目（如"2025年度数据传输运维人员服务"），需：
- 与上年项目对比，说明增减变化原因
- 沿用上年的项目结构和口径，保持一致性
- 如有预算调整，须详细说明原因

---

## 红线规则

以下内容**严禁**出现：

1. **禁止编造供应商报价**：没有真实报价来源时，标注 [需确认：需提供厂商正式报价]
2. **禁止虚报投资回报**：效益分析基于合理假设，不夸大经济效益
3. **禁止虚构政策依据**：不编造不存在的红头文件或上级指示
4. **禁止抄袭不相关项目内容**：每个项目必须针对其具体场景编写
5. **预算不得超范围**：如用户给定预算上限，所有测算不得超出该范围
6. **不得遗漏 [需确认] 标注**：所有不确定的信息必须显式标注，不得模糊带过

## 快速启动示例

### 示例1：设备采购立项

用户输入：
```
20套井场黑匣子设备采购立项，预算120万，供应商待定，2025年度
```

输出文件包：
1. 项目立项申请表 — "2025年度井场黑匣子设备采购"
2. 立项报告 — 含现有黑匣子老化分析、更换必要性、50口井覆盖方案
3. 技术要求 — 黑匣子硬件参数、防爆等级、数据采集协议、验收标准
4. 控制价格表 — 20套设备逐项报价，含安装费、运输费、税金
5. 一单一采说明 — 如用户指定单一来源则生成

### 示例2：人员服务立项

用户输入：
```
塔里木区域数据传输运维辅助人员服务立项，8人，2025年度，预算约150万
```

输出文件包：
1. 项目立项申请表 — "2025年度塔里木区域数据传输运维辅助人员服务"
2. 立项报告 — 含运维人员缺口分析、服务保障必要性
3. 技术要求 — 岗位职责、人员资质要求、KPI考核标准
4. 控制价格表 — 按岗位、人数、月薪、月数逐项测算

### 示例3：AI服务立项（2025年新增类型）

用户输入：
```
天翼云AI服务立项，用于录井数据智能分析，预算80万
```

输出文件包：
1. 项目立项申请表 — "天翼云AI智能录井分析服务"
2. 立项报告 — 含AI赋能录井业务必要性、行业趋势、预期效果
3. 技术要求 — 算力规格、模型要求、数据安全、平台功能
4. 控制价格表 — 算力租赁费、存储费、带宽费、技术支持费
