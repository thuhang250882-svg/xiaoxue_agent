# 女娲方法参考：离线蒸馏

本方法改编自 [alchaincyf/nuwa-skill](https://github.com/alchaincyf/nuwa-skill/tree/fe0374687037c4cc51a65c1e0c145afe2981dc69)，遵循其 MIT 许可。原版的 Claude 技能路径、联网采集、下载脚本、多代理编排和自动更新步骤不适用于小雪办公网运行。

## 采集维度

根据任务选择有证据的维度，不要求凑齐六类：

| 维度 | 本地可用证据 | 提炼目标 |
| --- | --- | --- |
| 作品与正式成果 | 已授权的报告、方案、制度、课程 | 稳定问题框架和核心概念 |
| 对话与教学 | 访谈纪要、培训记录、人工答复 | 解释顺序、追问方式和隐含判断 |
| 表达 | 经确认的改稿前后版本 | 常用结构、措辞和不采用的表达 |
| 实际决策 | 带结果的审核、整改或选型记录 | 条件、取舍、例外和停止点 |
| 价值与反例 | 明确的规范、否决案例、纠正记录 | 必须守住的边界 |
| 方法来源 | 被引用的标准、专家和历史版本 | 可追溯的依据及适用日期 |

每条结论记录“材料标识 + 位置 + 原始事实 + 提炼出的规则 + 可信度”。材料标识应是本地文件或任务定位符；不要复制整段敏感正文进 Skill。

## 提炼与构建

1. 从证据中归纳 3 至 7 个可操作的思维模型；每个模型至少回答“何时用、看什么、怎样判断、何时不能用”。证据不足时减少数量。
2. 把重复的判断写成条件规则。对冲突案例标注适用范围与版本，不以多数意见覆盖现行标准。
3. 区分表达风格与专业结论。可以学习专家的说明顺序，不把其个人语气当成业务要求。
4. 生成 Skill 的触发边界、输入、步骤、输出、异常处理和诚实边界。引用现有专业 Skill，而不复制其规则。
5. 用一份已知案例核对结果，再用一份边界案例检查误触发、证据缺失和权限。记录失败原因并修订。

## 小雪业务示例

- **录井报告审核**：从多次人工定稿提炼“先核来源，再核数据，再写批注”的顺序；数值阈值和地层判断仍需回到有效标准及原始数据。
- **单位周报**：从经确认的正式材料提炼固定栏目、口径与来源标注；信息化项目七板块报告另走其专用 Skill。
- **文档交付**：提炼原稿副本、标注版、最终版、预览和文件定位的检查点；可编辑性以真实格式能力为准。
