# 女娲：方法蒸馏

本技能改编自 [alchaincyf/nuwa-skill](https://github.com/alchaincyf/nuwa-skill) 的 `fe0374687037c4cc51a65c1e0c145afe2981dc69` 版本。原版关注人物或主题的思维方式；小雪也可用同一方法提炼经用户确认的内部专家经验。原版快照与许可见 `references/upstream-SKILL.md` 和 `LICENSE`。快照仅供方法参考，执行以本文件和当前任务的权限、保密要求为准。

## 工作流程

1. 确定蒸馏对象、用途、适用范围和已有 Skill。人物、主题与用户自己的工作方法分别标明，不把某人的言论当作经验证的业务规则。
2. 优先使用用户提供或已授权访问的一手材料。记录每条主张的来源位置、日期与证据强弱；缺少证据的维度留空。内部材料只在本地分析，不上传到公共搜索、云服务或外部仓库。
3. 提炼可执行的内容：3 至 7 个思维模型、关键判断规则、表达习惯、反例和诚实边界。区分“原材料直接支持”“分析推断”“尚待核实”。
4. 生成简短的 `SKILL.md`，把复杂案例、评分依据和模板放入按需读取的 `references/`。给出明确触发条件、输入、步骤、输出、例外与停止条件。新技能只写入用户指定或小雪当前项目的技能目录；覆盖已有技能前展示差异。
5. 用至少一个已知案例和一个边界案例试运行，检查结论能否追溯到证据、是否误触发其他业务技能。把未通过的条件写成限制，再交用户审阅。

## 业务约束

- 录井标准、合同条款、单位公文格式及审批规则以已提供的现行权威材料为准；人物观点不能替代它们。
- 不从少量对话推断用户的私人习惯、身份或敏感信息。需要提炼用户自身方法时，请其选择可用的任务记录或材料。
- 本技能负责“提炼方法和生成技能”。重复操作的自动发现、工作流候选及审批使用 `nuwa-workflow`。
- 不自动安装上游更新，不执行原版快照中的联网下载、外部发布或多代理步骤。仅在用户明确授权且环境允许时使用外部资料。

## 按需参考

- 需要原版六维采集、心智模型和质量评分时，读取 `references/upstream-SKILL.md` 的 Phase 1、2、4；其中的路径、联网和自动更新指令不适用于小雪。
- 需要为录井审核、周报或文档交付沉淀重复任务时，加载 `nuwa-workflow`。
