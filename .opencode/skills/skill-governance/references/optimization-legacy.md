# Skill 优化评分参考

此参考保留原“结构评估加效果验证”的有效方法，已移除外网仓库、自动建分支、自动回滚和成果卡片等不适合办公网治理的流程。

## 评分维度

| 维度 | 关注点 |
|---|---|
| 触发准确性 | description 能否区分相邻 Skill，正例和反例是否清楚 |
| 工作流 | 输入、步骤、输出和失败路径是否可执行 |
| 边界 | 是否限制外网、敏感数据、破坏性操作和未经确认的结论 |
| 资源 | references、scripts、assets 是否必要且路径可达 |
| 重复度 | 是否与已有 Skill 共用同一业务对象和交付物 |
| 实测 | 典型任务能否加载正确 Skill 并得到符合契约的结果 |

## 优化循环

1. 记录当前文件、触发样例和验证结果。
2. 每次只调整一个明确问题。
3. 运行结构校验、路由测试和一个典型任务干跑。
4. 只有验证改善且没有破坏边界时才保留修改。
5. 涉及删除或合并时先创建可恢复备份并记录映射。
