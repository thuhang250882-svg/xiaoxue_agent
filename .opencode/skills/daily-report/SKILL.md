# 生产运行日报汇总

## 目标

按源件形态执行且只执行一条路线：

- **路线 A：文字稿汇总。** 将各基层单位的 `.doc` / `.docx` 生产运行日报汇总为一份院级《地质研究院（录井工程分公司）生产运行日报》。正文按同类板块横向拼接，表格按同字段纵向堆叠并生成合计行。
- **路线 B：数据表汇总。** 将填报系统导出的《日报.xls》汇总为地质研究院生产日报、综合日报和生产市场动态表三张 `.xls`，同时生成处理报告。

源件是一口井一行的 26 列明细台账时走路线 B；源件是叙述性文字报告时走路线 A。两条路线的数据来源、统计口径和产物不同，不得混用。页面与表格参数已经固化，不询问用户排版参数。

## 工作流程

1. 清点用户授权范围内的源件、报告日期和应报单位，原件全程只读。无任何源件时停止，不凭记忆出稿。
2. 路线 A：
   - 读取 `references/structure.md`、`references/formats/01-日报版式.md` 和 `references/merge-rules.md`。
   - 使用小雪内置 `document_engine` 读取 `.doc` / `.docx`，不调用 WorkBuddy 编辑器或云端转换服务。
   - 按固定三段骨架归位；正文横向拼接，六张表纵向堆叠。缺报单位不补数，末尾列到报与未报清单。
   - 把内容写成标记文件，合计使用 `%SUM`，横向恒等关系使用 `%CK`，比例关系使用 `%CKR`。生成前必须准备 `--verify` 回验清单逐格核对源值。
   - 用 `XIAOXUE_PYTHON` 指向的随包解释器执行：

     ```text
     <xiaoxue-python> scripts/build_daily.py --selfcheck
     <xiaoxue-python> scripts/build_daily.py <内容标记.txt> <新的输出.docx> --verify <回验清单.txt>
     ```

   - `%CK` / `%CKR` 不平默认中断。只有确认属于报送单位原始矛盾、决定照录原值时，才可加 `--allow-unbalanced`，并把差异写入数据校核清单。回验差异只有逐条登记原始值、修正值和依据后，才可加 `--allow-src-diff`。
3. 路线 B：
   - 读取 `references/xls-source.md` 和 `references/xls-outputs.md`。
   - 采用 2026-09-21 确认的 `semantic` 口径：剔除“当日井深为空”，或“完井日期非空且施工状态为完井作业/修井”的记录。完井日期与状态矛盾的井保留，并列入“疑似状态矛盾井复核清单”。
   - 成品日期默认采用源数据日期；只有用户明确要求沿用历史命名日期时才设置 `--date-offset 1`。
   - 用随包解释器执行：

     ```text
     <xiaoxue-python> scripts/build_daily_xls.py --selfcheck
     <xiaoxue-python> scripts/build_daily_xls.py --src <日报.xls> --mode semantic --outdir <新输出目录>
     ```

   - 强制核对“剔除数 + 保留数 = 源行数”。每条剔除必须在处理报告中写明源行号、井号、施工状态和原因。
4. 两条路线开始前均运行 `scripts/check_environment.py --capability <能力>`。仅在状态为 `ready` 时生成正式文件；不得回退到系统 Python，不得在线安装依赖。
5. 生成后重新打开产物，核对文档/工作簿可读、页边距、字体、固定行距、表格、合计、实有行、处理报告和校核清单。目标文件存在时使用新文件名或新目录，不传 `--overwrite`。

## 输出格式

路线 A 必须同时交付：

- 新生成的院级生产运行日报 DOCX；
- 数据校核清单，逐条列不平项、口径冲突和经依据修正的原始值/修正值；
- 到报与未报单位清单；
- 源件回验和版式回读结果。

路线 B 必须同时交付：

- 地质研究院生产日报、综合日报、生产市场动态表三张新 XLS；
- 处理报告及疑似状态矛盾井复核清单；
- 剔除、保留、源行数守恒结果；
- “合计”与“实有（按井去重）”两行。全院井数和进尺只能取“实有”行，并与综合日报合计核对。

若随包运行时不可用，只交付带完整内容和规则的 Markdown/标记稿，明确标注“未生成 DOCX/XLS”，不得宣称正式文件已完成。

## 工作纪律

- 不推算缺报数据，不用昨日值、平均值或比例补齐源文件没有的量。队伍总数、未动用数、年累完成天、日增量进尺无源值时留空。
- 不擅自改单位自报数值；`%CK` 不平时照录并交报送单位确认。能够用同一单位其他字段证明笔误时，修正也必须登记原始值、修正值和依据。
- 不合并累计值与当日值、设备台数与井口数、自有与合作等不同口径。
- 不删除 `%SUM`、`%CK`、`%CKR`、`--verify`、去重实有行、条数守恒或疑点井清单等校验环节。
- 不覆盖或修改任何源件及既有产物；始终使用新的输出路径，不使用 `--overwrite`。
- 不上传内部材料，不调用公网、外部聊天记录或 WorkBuddy 专用接口。
- 不使用非方正字体，不加粗，不降低页面、行距、缩进或表格精度。路线 A 必须使用确定性生成器，不能以通用 `office_document` 替代。
