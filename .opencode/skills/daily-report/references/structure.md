# 院级生产运行日报结构定义

## 一、总体骨架

```
地质研究院（录井工程分公司）生产运行日报        #T
2026年09月20日 星期日                          #D

一、生产情况                                    #1
    1.录井                                      #2
        ……正文 + 表1
    2.实验检测                                  #2
    3.地质导向                                  #2
    4.信息化                                    #2
    5.液面检测、非满管、数字化坐岗仪             #2
    6.钻井风险防控工作                          #2
    7.增产总承包业务                            #2

二、设备动态                                    #1
    1.录井设备                                  #2
        ……正文 + 表2
    2.非满管及数字化坐岗仪                      #2
        ……正文 + 表3
    3.地化设备                                  #2
        ……正文 + 表4
    4.信息化设备                                #2
        ……正文 + 表5
    5.液面监测设备                              #2
        ……正文 + 表6

三、工作安排                                    #1
四、本日数据报送情况                            #1
```

前三者（一、二、三）是固定的业务骨架；第四块"本日数据报送情况"是汇总过程说明，用于标注缺报，属于必备收尾。

## 二、生产情况各板块的数据来源

| 板块 | 由谁报送 | 汇总方式 |
|---|---|---|
| 1.录井 | 各项目部、各分院 | 各单位自报原句并列 + 表1 纵向堆叠 |
| 2.实验检测 | 各分院、实验检测中心 | 各单位自报原句并列（冒号前标单位） |
| 3.地质导向 | 地质工程一体化中心 + 吐哈/西南/长庆各分院 | 各单位自报条数**相加**，分布逐项合并 |
| 4.信息化 | 数据中心 + 各分院 | 各区域在用套数相加 |
| 5.液面检测、非满管、数字化坐岗仪 | 各项目部、各分院、数据中心 | 按设备类型分四条叙述，各区域数相加 |
| 6.钻井风险防控工作 | 地质工程一体化中心 | 整段照录 |
| 7.增产总承包业务 | 地质研究中心（单独报"增产总承包业务日报"） | 整段照录 |

**注意**：地质导向是唯一需要把多家数量相加的板块。一体化中心报的是"今日导向跟踪 N 口"的主体部分，吐哈、西南、长庆各报自己那几口，加总才是全院口径。年累值同理。

## 三、六张表的字段定义

### 表 1 · 录井工作量（单行表头，6 列）

| 区域 项目 | 综合（口） | 气测（口） | 常规（口） | 特殊（口） | 合计（口） |
|---|---|---|---|---|---|

各单位原样堆叠，末行为"录井总计"。合计（口）必须是前四列之和，用 `ADD:2,3,4,5` 自动算。

### 表 2 · 录井仪动用率（两行合并表头，11 列）

分组行：`油田区域 | 自营设备（台）^7 | 合作设备动用（台）^1 | 设备合计^2`
子表头：`油田区域 | 总数 | 正录 | 待录 | 待搬 | 等停 | 动用数 | 动用率 | 合作设备动用（台） | 动用设备总数 | 自主施工占比`

合计行指令：`SUM ×7 ；RATE:7/2（动用率）；SUM（合作）；ADD:7,9（动用设备总数）；RATE:7/10（自主施工占比）`

内部恒等关系（用于校验）：

```
总数 = 正录 + 待录 + 待搬 + 等停
动用数 = 正录 + 待录 + 待搬
动用设备总数 = 动用数 + 合作设备动用
```

### 表 3 · 非满管及数字化坐岗仪（两行合并表头，11 列）

分组行：`油田区域 | 非满管^5 | 数字化坐岗仪^5`
子表头：`油田区域 | 总数 | 正录 | 等停 | 维修 | 动用率 | 总数 | 正录 | 等停 | 维修 | 动用率`

合计行：`SUM×4 ；RATE:3/2 ；SUM×4 ；RATE:8/7`

内部恒等：`总数 = 正录 + 等停 + 维修`

### 表 4 · 地化设备（单行表头，8 列）

| 使用单位 | 设备类型 | 完好总数 | 动用 | 待命 | 待维修 | 设备停用 | 无法修复待报废 |
|---|---|---|---|---|---|---|---|

按"单位 + 设备类型"逐行铺开。各单位自报的设备类型清单不完全一致，照各单位实际列示，**不强行对齐**。末行标签两格均写"设备汇总（台）"。

### 表 5 · 信息化设备（两行合并表头，5 列）

分组行：`使用区域 | 自有^4`
子表头：`使用区域 | 在用 | 等停 | 损坏 | 合计（套）`

内部恒等：`合计 = 在用 + 等停 + 损坏`

### 表 6 · 液面监测设备（单行表头，5 列）

| 使用区域 | 在用 | 等停 | 故障维修 | 合计（套） |
|---|---|---|---|---|

合计（套）用 `ADD:2,3,4` 自动算，保证与分项自洽。

## 四、内容标记与结构的对应关系

| 结构层级 | 标记 |
|---|---|
| 文档标题 | `#T` |
| 日期行 | `#D` |
| 一级标题 | `#1` |
| 二级标题 | `#2` |
| 正文段落 | 直接写文本 |
| 表格 | `%W` / `%G` / `%S` / `%R` / `%SUM` / `%E` |

详情用 `python scripts/build_daily.py --list` 查看。
