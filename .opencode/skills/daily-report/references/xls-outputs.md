# 三张院级汇报表：结构与口径

脚本：`scripts/build_daily_xls.py`。源字段规范见 `xls-source.md`。

## 一、产出清单

文件名日期取自日报数据日期：

```
地质研究院生产市场动态表YYYY-MM-DD.xls
地质研究院综合日报YYYY-MM-DD.xls
地质研究院生产日报YYYY-MM-DD.xls
```

另附 `日报汇总处理报告-YYYY-MM-DD.md`：条数校验、剔除明细、产出清单。

## 二、地质研究院生产日报

**＝ 源表原样搬移，只做两件事：换标题、剔除不合格井。**

- 26 列表头逐字照抄（含 `当日井深(m)` 这类带单位的写法）
- 每格字面值照抄，不转数值、不改小数位
- 每格样式沿用源单元格自身样式，列宽沿用源列宽
- 冻结窗格：前 3 行 + 前 3 列
- 剔除后行整体上移，连续无空行

## 三、剔除口径（三选一，`--mode` 切换）

已用穷举法验证：**不存在任何能还原历史结果的源字段规则**——对全部候选字段（当日井深、开钻日期、开始录井时间、完钻井深、完钻日期、固井日期、完井日期、录井队号、录井仪器型号、录井单位）做 1~3 元 AND 组合共数百种，无一命中历史剔除集合。因此提供三种口径：

| 模式 | 规则 | 本批结果 | 适用 |
|---|---|---|---|
| `semantic`（**2026-09-21 起为业务确认口径**） | 未录井＝当日井深为空；已完井＝**完井日期非空 且 施工状态命中「完井作业/修井」**（`DONE_STATUS_KEYWORDS`） | 152 → 剔除 6 → **146** | 日常默认推荐 |
| `history` | 「当日井深为空」＋ 显式井号清单兜底 | 152 → 剔除 4 → **148** | 复刻历史成稿时用 |
| `none` | 不剔除 | 152 | 只需原表搬移 |

**疑点井机制（semantic 自动启用）**：完井日期与施工状态不匹配的井**保留入表**并登记，处理报告单列「疑似状态矛盾井复核清单」交人工确认。三类疑点：
1. 完井日期非空但状态非完井作业/修井（如固井候凝、四开却填了完井日期——状态与日期矛盾）；
2. 状态为完井作业/修井但完井日期为空（日期疑漏填）；
3. 完井日期无法解析且状态不命中白名单。

`history` 模式不受影响，不产生疑点清单。

### history 模式的第 4 口井

历史成稿剔除的 4 口是：`佳31-3`(一开准备)、`太资4X`(设备搬迁)、`李庄2-22`(安装设备)、`ZJHW1313`(处理复杂)。

前三口可由「当日井深为空」命中。第四口 `ZJHW1313` 已钻至完钻井深 5171m、完钻日期 2026-08-19，但同条件的还有 27 口井被历史保留，且其录井单位为外部单位（新疆广陆能源科技股份有限公司）——三者都无法单独构成判据，**判定含人工成分**，故以 `WELL_EXCLUDE_OVERRIDE` 常量兜底。

如需改判定逻辑，改该常量即可，不要试图再加字段规则。

### 验证

`history` 模式输出的 148 行，与历史成稿 `地质研究院生产日报2026-09-12.xls` 的数据区 **151 行 × 26 列逐格比对，0 处差异**。这是该口径唯一可信的凭证，每次改动后应重新比对。

## 四、地质研究院综合日报

**维度**：行 = 录井分公司（业务科室）；列 = 指标 + 各录井系列井数。

| 列 | 内容 |
|---|---|
| 业务科室 | 录井分公司取值降序排列 + 末行「合计」 |
| 井数(口) | 有效井数 |
| 累计进尺(m) | 当日井深之和 |
| 探井(口) / 开发井(口) | 按井别归并，见下 |
| 自营(口) / 合作(口) | 按 DWTYPE |
| 动用队伍(支) | 录井队号去重计数 |
| 录井系列（口） | 综合/气测/地质/地质导向/液面监测/地化/元素录井/常规/一般/池体积监测/EISC，表内未列者归「其他」 |

**井别归并**（源表 14 种取值，纯业务口径推定，需由对口业务科室确认）：

- 探井 ← 探井、预探井、风险探井、资料井、评价井、风险井
- 开发井 ← 开发井、采油井、采气井、注水井、注气井、生产井、开发试验井、矿场井

## 五、地质研究院生产市场动态表

**维度**：行 = 地区（服务油田）× 录井系列（设备类型），油田名纵向合并；列 = 自营/合作 × (动用队伍、井数、累计进尺) + 合计进尺。

- 自营/合作按 DWTYPE 划分
- 末行「合计」

### 「合计」与「实有（按井去重）」两行并存

录井系列是**复合字段**，一口井填了"综合+地质导向+液面监测"就会分别计入三行。所以「合计」行的井数与进尺是**按类型累加**值，必然大于全院实有值——本批 173 口 / 611134 m，而实有只有 148 口 / 530691 m。

两张数都要给，且**不许只给一个**：

| 行 | 含义 | 何时用 |
|---|---|---|
| 合计 | 按设备类型累加，各类型工作量之和 | 报"各类型完成了多少工作量" |
| 实有（按井去重） | 按井号去重，全院真实井数与进尺 | 报"全院今天干了多少口井、多少米" |

**全院井数、全院进尺一律取「实有」行的值**；拿「合计」行当全院数会虚增约 16%。综合日报的合计行本身就是按井统计的，与动态表「实有」行必然相等——这个相等是两表互证的第一道关，对不上就是去重逻辑坏了。

> 历史样例《动态表》里有 `Sheet2`(填报时间 2026-06-16) 和 `Sheet3`(2025/2/28) 两个**陈旧残留页**，属手工过程中的脏数据，本生成器**不复制**，只产出一张干净的活动表。

> 历史样例的服务油田行是按**固定骨架**铺的（含当日无井的苏里格油田、河南平顶山等空行）。本生成器默认按当日实际出现地区输出。需要固定骨架时用 `--oilfield-list` 提供清单。

## 六、全部假设清单

| # | 假设 | 调整方式 |
|---|---|---|
| 1 | 成品日期 = 数据日期 + 偏移，默认 0。历史样例为 +1（源 09-11 → 成品 09-12） | `--date-offset 1` 或 `--report-date` |
| 2 | 进尺 = 当日井深求和。源表无独立进尺字段，也无昨日井深，算不出日增量 | 需日增量须另给数据源 |
| 3 | semantic 模式下：未录井 = 当日井深为空；已完井 = 完井日期非空 | 改 `classify()` |
| 4 | history 模式第 4 口井以显式清单兜底（已证明无字段规则可还原） | 改 `WELL_EXCLUDE_OVERRIDE` |
| 5 | 录井系列按 `、+，,/` 拆分后分项计数 | 改 `SERIES_SPLIT` |
| 6 | 综合录井→综合、池体积检测→池体积监测 | 改 `SERIES_ALIAS` |
| 7 | 14 种井别归并为探井/开发井 | 改 `WELL_TYPE_MAP` |
| 8 | 队伍总数/未动用数/年累完成天源表没有，**留空不推算** | 提供花名册后接入 |

假设 1~8 全部写进了每个成品表的**批注区**，读表人不必打开脚本也能看到口径。

## 七、命令与校验

```
python build_daily_xls.py --selfcheck                 # 16 项内置自检
python build_daily_xls.py --src 日报.xls              # 默认 semantic 确认口径
python build_daily_xls.py --src 日报.xls --mode semantic
python build_daily_xls.py --src 日报.xls --date-offset 1    # 复刻历史文件命名
python build_daily_xls.py --src 日报.xls --exclude-file 清单.txt
```

脚本强制输出「剔除数 + 保留数 = 源行数」守恒校验，不通过即返回码 3 中断，**不允许带着不平和出稿**。

### 数值与边界的四条纪律

1. **数值解析失败返回 `None`，不得当 0**。源表全部单元格是文本，含 `5600.0000` 这类写法。解析失败若按 0 处理，进尺会悄悄变小且无任何提示。解析不出的行必须显式报出。
2. **井号唯一性校验**。筛选后逐行查井号重复；重复说明上游导出把同一口井导了多次，计数会翻倍，必须中断而不是照出。
3. **`semantic` 模式的完井日期要与数据日期比**。只判"完井日期非空"会把**未来日期**也当成已完井误剔；正确判据是完井日期非空**且不晚于数据日期**。
4. **字段名按名精确匹配**。源表实为 `当日井深(m)`，写成 `当日井深` 会匹配失败——若脚本靠列序号兜底，列顺序一变就静默取错列。新增列时先改 `COL`，再跑 `--selfcheck`。

## 八、绝不做什么

- **不动源文件**。全程只读；目标文件名若已存在，默认依次另存为 `-新稿.xls`、`-新稿-2.xls` 等不存在的新名称；只有显式 `--overwrite` 才覆盖且自动进 `_backup_时间戳\`。
- **不算源表没有的量**。队伍总数、未动用数、年累完成天、日增量进尺一律留空。
- **不虚构油田行**。当日无井的地区不出现在动态表里，除非给了固定骨架清单。
- **不把复合系列横向相加冒充井数**。系列之和大于井数是字段性质，在批注里写明而非偷偷去重。
