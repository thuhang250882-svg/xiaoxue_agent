# 生产运行日报版式规范（唯一参数来源）

从 15 份单位原始件与院级历史汇总件逐份实测逆向提取。两套素材的版式均已被破坏（Word 默认边距、非方正字体、行距忽 24 磅忽 28 磅忽 1.5 倍），**不可作为范本**。本规范采用西部钻探公文标准，与 weekly-report 技能的版式基线完全一致。

## 一、页面设置

| 项目 | 取值 |
|---|---|
| 纸张 | A4 21.00 × 29.70 cm，纵向 |
| 页边距 | 上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm |
| 版心宽度 | 15.60 cm |
| 页眉距 / 页脚距 | 1.5 / 1.75 cm |
| 页脚 | 居中页码域（PAGE） |

## 二、字体字号与行距

| 层级 | 字体 | 字号 | 对齐 | 首行缩进 | 行距 |
|---|---|---|---|---|---|
| 文档标题 | 方正小标宋简体 | 二号 22pt | 居中 | 0 | 固定 32 磅 |
| 日期行 | 方正黑体简体 | 三号 16pt | 居中 | 0 | 固定 32 磅 |
| 一级标题（一、二、…） | 方正黑体简体 | 三号 16pt | 左 | 2 字符 | 固定 28 磅 |
| 二级标题（1. 2. …） | 方正楷体简体 | 三号 16pt | 左 | 2 字符 | 固定 28 磅 |
| 正文 | 方正仿宋简体 | 三号 16pt | 左 | 2 字符 | 固定 28 磅 |
| 表格内文字 | 仿宋 | 小四 12pt | 居中 | 0 | 单倍 |

**关键约束**

- **全文不加粗**。层级靠换字体区分，不靠加粗、不靠放大字号。
- **行距必须写"固定值"**。这是版式一眼可辨的一致项；用单倍或多倍都会跟标准件对不上。
- 首行缩进统一 32 磅（2 字符 × 16pt），段前段后间距全为 0。
- 标题/表格前的提示句（如"录井仪动用率统计表"）按正文处理。

## 三、日期行写法

统一为 `2026年09月20日 星期日`：月份、日期两位补零，末尾带星期。单位源件常写成 `2026年9月20日`（不补零、无星期），汇总时统一到本标准写法。

## 四、编号体系

- 一级：`一、` `二、` `三、`（中文数字 + 顿号），写死在文本里，不用 Word 自动编号。
- 二级：`1.` `2.` `3.`（阿拉伯数字 + 半角点），同样写死。
- 二级下的并列短句（如"液面监测：……""非满管：……"）不另起标题，作为独立正文段落，靠冒号前的名词区分。
- 同稿内不得混用两种编号。

## 五、表格规格

| 项目 | 规格 |
|---|---|
| 字体 | 仿宋 |
| 字号 | 小四 12pt |
| 对齐 | 全部单元格水平居中、垂直居中 |
| 边框 | 全线框（上下左右 + 内部横竖），单线 sz=4 |
| 表头 | 支持两种：**单行表头**（表 1、表 4、表 6）与**两行合并表头**（表 2、表 3、表 5） |
| 两行表头结构 | 第 1 行为分组名（横向合并 gridSpan），第 1 列纵向合并到底 2 行（vMerge restart / continue） |
| 列宽 | 按 `%W` 权重分配，**合计必须等于版心宽 15.60 cm** |
| 表头行 | 标记 `tblHeader`，跨页自动重复 |

单元格内不得用 Tab 或空格做缩进，一律靠居中或换行对齐。

## 六、段落长度

单段超过 320 字时自动按句号切分；切完仍超的再按分号切。目的是避免整页大段文字——日报虽然以短句为主，但"增产总承包业务"这类条目常有一两百字的整段，需要按句断开。

## 七、与其他技能的一致性

本套参数与 `weekly-report` 技能的 `references/formats/` 完全同源。若两处出现不一致，以本文件为准（本文件为较新的实测结果），并同步修正 weekly-report。
