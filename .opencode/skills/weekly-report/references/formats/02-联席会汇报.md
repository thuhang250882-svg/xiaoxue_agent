# 周工作联席会汇报（塔里木分院）

**报送对象**：地质研究院（录井工程分公司）周工作联席会。
**定位**：五段式公文，全套里排版要求最严的一套。段落内容由聊天记录汇总而来，因此每一条都要能说清"从哪来的"。

## 一、页面设置（公文标准）

| 项目 | 值 |
|------|-----|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm |

## 二、字体字号与行距（六层结构）

| 层级 | 字体 | 字号 | 缩进 | 行距 |
|------|------|------|------|------|
| 文档标题 | 方正小标宋简体 | 二号（22pt） | 7 字符（154pt） | 固定值 32 磅 |
| 分节标题（单位名） | 方正小标宋简体 | 二号（22pt） | 居中 | 固定值 32 磅 |
| 时间段行 | 方正仿宋简体 | 三号（16pt） | 2 字符（32pt） | 固定值 28 磅 |
| 一级标题 | 方正黑体简体 | 三号（16pt） | 2 字符 | 固定值 28 磅 |
| 二级标题 | 方正楷体简体 | 三号（16pt） | 2 字符 | 固定值 28 磅 |
| 正文 | 方正仿宋简体 | 三号（16pt） | 2 字符 | 固定值 28 磅 |

**全文不加粗**，标题层级靠换字体区分。段前段后一律 0。

**行距必须写"固定值"**，不能用单倍或多倍——实测单位原始件正文为固定值 28 磅、标题为固定值 32 磅，这是版式一眼可辨的一致项。

首节"一、周、月度会安排工作落实情况"在历史文档中使用 Word 自动编号，生成时直接写死"一、"即可，效果一致。

### 编号体系

| 层级 | 格式 | 示例 |
|------|------|------|
| 一级 | 中文数字 + 顿号 | `一、` `二、` `三、` |
| 二级（生产运行部分） | 阿拉伯数字 + 半角点 | `1.工作量完成情况` |
| 二级（其他部分条目） | 阿拉伯数字 + 顿号 | `1、` `2、` `3、` |
| 三级 | 圆括号中文数字 | `（1）` `（2）` `（3）` |

**同一份稿内二级编号不得混用**：生产运行部分统一用半角点，完成主要工作、协调问题、后续安排三节统一用顿号。

## 四、表格规格

工作量、设备动用这类分区域数据用表格，实测规格固定：

| 项目 | 值 |
|------|-----|
| 字体字号 | 仿宋，小四（12pt） |
| 对齐 | 表头与数据行一律居中 |
| 边框 | 全线框，单实线（sz=4，约 0.5 磅） |
| 列宽 | 按源表比例缩放，总宽等于版心宽（442.2pt） |
| 表头 | **两行合并表头**：第一行分组名（横向合并 `gridSpan`），第一列纵向合并 `vMerge` 到第二行 |
| 跨页 | 两行表头设为重复标题行，数据行禁止跨页断行 |

两行表头结构举例（工作量表，9 列）：

```
行1：区块（纵向合并） | 周计划（天）〔横跨2列〕 | 周完成（天）〔横跨2列〕 | 周完成率 | 年累完成 | 年度计划 | 完成比例
行2： 同上（纵向承接） |     自有    |    合作     |    自有     |   合作    |  同上（纵向承接）×4  ......
```

**不要把表头压成一行**——单行表头放不下"周计划（天）—自有／合作"这类层级，会把列名拆成乱码式的"周完／成率"。

> 2、【数据传输运维】完成8月29日信息化用车计划的报车及审核。（分院后勤管理群）。
> 6、【经营统计与结算】处理并与任力新确认2-6月与巴州电信公司的结算材料及扣费事项。（与任力新的对话）。

**现有分类标签**（按需扩展，不臆造新标签）：

### 需要科室、领导协调的问题

每条以"需"开头，说清**诉求 + 对象**：

无问题时写 `无。`

### 后续的主要工作安排
