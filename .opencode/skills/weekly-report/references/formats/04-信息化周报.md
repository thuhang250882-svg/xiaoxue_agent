# 西部钻探信息化服务项目部周工作汇报

**报送对象**：项目部 / 巴州分公司内部。
**定位**：内部周报，与甲方周报同源但**更粗**——保留总量数字，不摊明细。

## 一、页面设置

| 项目 | 值 |
|------|-----|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上 2.5cm / 下 2.5cm / 左 2.4cm / 右 2.4cm |

## 二、字体字号

| 层级 | 字体 | 字号 | 说明 |
|------|------|------|------|
| 大标题 | 方正小标宋简体 | 二号（22pt） | 如 `钻试修井场信息化服务周工作情况汇报7.10` |
| 一级标题 | 方正黑体简体 | 三号（16pt） | 加粗，缩进 2 字符 |
| 正文 | 方正仿宋简体 | 三号（16pt） | 缩进 2 字符 |

## 三、结构骨架

```
一、本周重点工作
二、本周专项治理工作
三、本周存在问题
四、下周工作重点
```

## 四、行文口径

**与甲方周报的差别，只看详略：**

| 内容 | 甲方周报 | 信息化周报 |
|------|---------|-----------|
| 服务井总数 | 按四个事业部分口径拆开 | 可按事业部拆，也可只留总数 |
| 设备安装／回收 | 井号全部列出 | 只留数量 |
| 运维次数 | 含远程运算时标注 | 同上 |
| 专项治理 | 单独一节 | 单独一节（等价） |

写法示例：

> 1.信息化服务动态：目前总计服务井119口（2口正在安装）。其中钻井104口（勘探事业部26口、产能建设事业部78口）、试油1口（勘探事业部1口）、井下作业14口（九大油气开发部：4口；勘探+产建10口）。
> 2.本周完成5口井信息化设备安装、完成5口井的设备回收工作、正在安装井2口累计运维89次。

- 承包商结算、合同谈判、工作量确认、设备采购与置换类事项写在"本周重点工作"里，作为独立条目。
- 数据接入类事项写明接入井数与井号（`本周总计接入LWD数据两口：TZ40-H29、富源212-H4，数据均已回传至油田DROC。`）——这一项即使在本套里也保留井号。
- 存在问题为空时写 `无`（不带句号，与甲方周报的 `无。` 不同）。
- 篇幅：约 620 字。

## 五、含A12 变体

文件名标注"含A12"的期次，内容中包含 A12 项目的服务动态与结算条目，在"本周重点工作"内单列。（A12 条目在样本中的位置不固定，出文档时置于首条服务动态之后。）
