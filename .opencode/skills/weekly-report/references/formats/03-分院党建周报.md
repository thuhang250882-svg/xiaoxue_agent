# 党建工作及信息化服务周工作

**报送对象**：塔里木分院（内部）。
**定位**：党建与信息化两块合并的短周报，五套里篇幅最短。

## 一、页面设置

| 项目 | 值 |
|------|-----|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | 上 2.5cm / 下 2.5cm / 左 2.4cm / 右 2.4cm |

## 二、字体字号

| 层级 | 字体 | 字号 | 说明 |
|------|------|------|------|
| 大标题 | 方正小标宋简体 | 二号（22pt） | 标题末尾接日期，如 `党建工作及信息化服务周工作6.25` |
| 板块标题 | 方正黑体简体 | 三号（16pt） | 加粗，缩进 2 字符 |
| 正文 | 方正仿宋简体 | 三号（14pt） | 缩进 2 字符 |

注意本套正文用 **14pt**，比其余四套小一号，是与甲方周报、信息化周报的显著区别。

## 三、结构骨架

```
党建工作及信息化服务周工作6.25        ← 小标宋二号
信息化服务                            ← 黑体16pt加粗
    1.塔里木油田信息化服务动态：服务井总计120口。其中钻井+试油107口，修井作业13口。
    2.本周完成5口井信息化设备安装、完成5口井的设备回收工作、正在安装井3口累计运维92次。
    3.A12服务动态：服务井18口，累计运维10次。
    4.…（合同、结算、承包商工作量等）
    下周重点工作                      ← 板块内引导行，不带编号
        1.…
党建工作                              ← 黑体16pt加粗
    1.讨论制定"七一"主题党日活动方案；
    2.及时上报二季度劳动竞赛材料。
```

## 四、写法口径

- **两块顺序固定**：先"信息化服务"，后"党建工作"。两者都不带"一、二、"编号，直接写板块名。
- 信息化服务部分开头**两条固定内容**：
  1. 塔里木油田信息化服务动态——总数 + `钻井+试油 / 修井作业` 两分（注意：不按四个事业部分，比甲方周报粗）
  2. 本周设备安装、回收、正在安装、累计运维——只给数字，**不列井号**
- 涉及 A12 时单列一条服务动态。
- "下周重点工作"是板块内的引导行，本身不带编号，其后条目重新从 1 开始编号。
- 党建工作条目写活动名称与动作，如主题党日方案、劳动竞赛材料上报、专项治理学习、疫情防控信息上报。
- 篇幅：约 410 字，10–15 条。
