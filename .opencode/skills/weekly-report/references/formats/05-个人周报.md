# 个人工作周报

**报送对象**：本人留档 / 向直接上级简要汇报。
**定位**：只记本人主办事项，不计总量、不分类、不排版。

## 一、页面设置

| 项目 | 值 |
|------|-----|
| 纸张 | A4（21.0 × 29.7 cm） |
| 页边距 | Word 默认（上下 2.54cm / 左右 3.17cm） |

## 二、字体

不显式设置字体，沿用默认字体，保持朴素。正文 10.5pt 起。

## 三、结构骨架

```
本周主要工作：
    完成中石化西北局信息化传输方案的编制。
    完成巴州分公司A12合同的草拟。
    完成渤海钻探、巴州浩展合同及技术指标的编写。
    …（10 条左右）
下周主要工作：
    巴州分公司A12合同的谈判。
    督促魏伯承、刘长青、王召完成信息化设备库房盘库、整理，并对设备进销存台账进行审核。
    …
```

## 四、写法口径

- **两段固定引导行**：`本周主要工作：`、`下周主要工作：`
- 一行一事，不编号、不分类、不写来源
- 动词开头收尾带句号：完成／参加／针对／督促／跟进
- 完成量可以带数字，但不铺明细：
  > 完成承包商3-6月份工作量统计，并与各家进行核对。
  > 本周接入定向井LWD数据6口，进步巨大。
- 涉及具体责任人的事项写清对象：`督促魏伯承、刘长青王召完成…`
- 下周事项与本周未结事项呼应，一条一个行动项
- 篇幅：约 460 字，本周 10–13 条、下周 3–5 条
