# 本周事实底稿

五套周报都从这一份事实派生：**先把事实填齐，再按目标那套的口径改写**。
事实没拿到就写 `〔待补充〕`，不推测、不四舍五入、不编井号。

## 一、服务规模

| 字段 | 说明 |
|------|------|
| 服务井总数 | 分钻井 / 试油 / 井下作业，各自再按事业部拆：勘探事业部、产能建设事业部、九大油气开发部、勘探+产建 |
| 正在安装井数 | 单独计数，不计入已完成 |
| A12 服务井数与运维次数 | 仅涉及 A12 时填 |

## 二、本周设备动态

- 完成安装：井数 + 具体井号（按钻井 / 井下作业分组）
- 正在安装：井数 + 具体井号
- 完成回收：井数 + 具体井号
- 累计运维次数（含远程运维时标注）

## 三、数据接入

- 本周接入的专项数据：LWD / 试油 / 定向，井数与井号
- 数据回传去向（如油田 DROC）
- 数据中断情况：超 6 小时的中断井（需列表时用表格）

## 四、合同与经营

- 合同进展：签订 / 延期 / 谈判 / 审批所处节点
- 结算进度：期次起止、金额（保留两位小数）、签字确认状态
- 承包商工作量确认：单位、期间、金额
- 收入：累计收入、录井收入、信息化收入（万元，两位小数）

## 五、人员与设备台账

- 人员：自有员工数 / 第三方人数、在岗数 / 轮休数
- 设备：动用台数、自有设备总数、合作设备、液面监测设备、元素设备、信息化设备套数
- 车辆与运维保障：区域、人数、车数

## 六、问题与协调

- 需要科室、领导协调的问题：诉求 + 对象
- 现场暴露的问题：现象 + 原因 + 当前处置状态

## 七、党建工作

- 主题党日、劳动竞赛、学习培训、专项治理、信息上报

## 改写矩阵：同一份事实，五套怎么用

| 目标 | 详略控制 | 特别要求 |
|------|---------|---------|
| 甲方周报 / 旬报 | 全字段展开，**井号必须列全** | 服务井数按四事业部分口径拆开；无问题写 `无。` |
| 信息化周报 | 保留总量数字，井号可只留数量 | 数据接入类保留井号；无问题写 `无` |
| 联席会汇报 | 按五段式归类 | 每条带分类标签与来源标注；生产运行部分数字密度最高 |
| 分院党建周报 | 压到 400 字左右 | 只取信息化 + 党建两块；信息化开头只给总数与两项分 |
| 个人周报 | 只取本人主办事项 | 一行一事，不带来源和分类 |

**口径隔离**：五套产出互不串用。给甲方的明细不自动出现在信息化周报里，联席会的分类标签不出现在其他四套里。
