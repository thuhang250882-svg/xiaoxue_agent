# 环节 3：分类标签配置规范

## 七大固定分类（系统枚举，不可自造）

入库时 `import` 必须指定且只能指定其一；判定按"资料的主要用途"，一份资料只入一个分类。

| category | 中文名 | 判定标准（按优先级） | 典型例子 |
|----------|--------|---------------------|---------|
| `standard` | 标准规范 | 国家/行业/企业标准，编号含 GB、SY、Q/SY、Q/SH 等 | QSY 01018.3 录井数据规格 |
| `company_rule` | 公司制度 | 管理办法、实施细则、内控文件 | 报告审核管理办法 |
| `template` | 报告模板 | 填空型模板、格式规范文件 | 录井月报模板 |
| `excellent_report` | 优秀报告 | 已完成的成品报告，供参考借鉴 | XX井解释总结优秀报告 |
| `expert_experience` | 专家经验 | 个人经验总结、技术窍门、案例分析 | 气测解释经验汇编 |
| `tender_case` | 投标案例 | 标书、投标响应文件、评标记录 | XX项目投标文件 |
| `contract_case` | 合同案例 | 合同文本、补充协议、纠纷处理 | 技术服务合同范本 |

### 分类判定顺序

1. 有标准编号 → `standard`
2. 是"要求别人怎么做事"的约束性文件 → `company_rule`
3. 是"拿来填/套用"的空白框架 → `template`
4. 是"已完成成果" → 按领域选 `excellent_report` / `tender_case` / `contract_case`
5. 是"个人Know-how" → `expert_experience`
6. 仍无法判定 → 列出疑似分类请提交人确认，**不得默认塞 standard**

## 标签配置规范

当前系统的标签能力 = 固定分类（`category`）。规则：

- **入库时必填 category**；检索时可按 categories 过滤。
- 命中结果的 `hit.category` 即标签，直接来自索引记录（受控入库时写入），不由目录名猜测。
- 标题命名规范：`〔编号或主题〕〔名称〕〔版本/年份〕`，例：`QSY 01018.3-2018 勘探与生产数据规格 第3部分：录井`——标题参与检索且权重 3 倍，规范命名直接影响检索命中。
- 自由标签、多级目录为未实现能力（见测试报告缺口清单），各部门不要在 title 里堆砌标签词冒充标签（如"【必看】【热门】"），会污染检索权重。
