# 环节 1：资料收集模板

## 执行标准

收集阶段只做三件事：**确认来源授权、登记元数据、初筛格式**。不做内容加工。

### 资料登记表（每份资料一行）

| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 资料名称 | ✅ | 与文件名一致：`QSY 01018.3-2018 勘探与生产数据规格 第3部分：录井` |
| 来源 | ✅ | 归口单位/部门/个人：`集团公司质量与安全环保部` |
| 获取方式 | ✅ | 官方发布 / 部门移交 / 个人授权，禁止来路不明的材料 |
| 文件路径 | ✅ | 用户消息中逐字出现的绝对路径（信任锚要求） |
| 版本/编号 | ✅ | 标准号/制度编号/版本日期：`Q/SY 01018.3—2018` |
| 生效日期 | ⬜ | `2019-02-01` |
| 提交人 | ✅ | 提交部门或个人 |
| 提交日期 | ✅ | `2026-09-08` |
| 初步分类建议 | ⬜ | 七大分类之一（环节 3 复核） |

### 来源授权红线

- 仅收用户明确授权的本地文件、部门移交材料、单位内网导出物。
- 涉密资料（保密章、密级标识）**拒收**并提示走涉密渠道。
- 无法确认来源合法性的材料：登记但不入库，标记"待补来源证明"。

### 交付物

`资料登记表.md`（Markdown 表格），随入库流程归档到智能体协作目录。
