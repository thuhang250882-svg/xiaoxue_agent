# 招标文件解析与审核

用于解析地质录井、钻井工程、油气田技术服务、资料解释评价、设备采购和软件平台类招标文件，把长文件拆成投标响应清单、风险清单和证据化审核意见。

## 核心原则

- 只基于当前招标公告、招标文件、答疑澄清、补遗、技术规范和评分办法下结论。
- 区分硬性废标条款、评分加分项、一般响应项和商务谈判风险。
- 每条判断都给出条款编号、章节、页码或可检索原文片段。
- 行业经验只能作为建议核查或响应建议，不能写成文件事实。
- 缺少附件、图纸、工程量清单或合同格式时，列为待补充材料。

## 审核流程

1. 提取项目名称、招标人、标段、服务地点、服务周期和工作量。
2. 梳理资质、业绩、人员、设备、HSE、质量体系、投标保证金、签章和授权要求。
3. 拆解岩屑、气测、工程、荧光、地化、资料解释、数据接口和现场值守等技术响应点。
4. 拆解评分办法，区分客观得分证据和主观方案表达重点。
5. 审核最高限价、报价方式、付款、履约担保、违约责任、保密、资料归属和安全环保责任。
6. 输出废标点、风险等级、需准备材料和投标响应建议。

## 常见风险模式

- 同类业绩定义过窄，现有业绩可能无法被认定。
- 人员证书、社保、注册单位和投标主体不一致。
- 技术规范要求设备型号、精度或接口，但投标方案未逐项响应。
- 报价包含耗材、驻井交通、系统接入、第三方检定等隐性成本但未计价。
- 付款以甲方最终结算、审计或上游付款为前提，回款周期不可控。
- 合同格式中违约责任单向偏重，缺少甲方配合、停工、变更签证条款。
