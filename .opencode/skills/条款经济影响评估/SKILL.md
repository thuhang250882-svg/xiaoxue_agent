# /条款经济影响评估 -- 合同条款经济量化分析

> 如遇到不熟悉的占位符或需检查已连接工具，参见 [CONNECTORS.md](../../CONNECTORS.md)。

量化评估合同条款变动带来的经济损失或收益，辅助谈判决策和风险承受判断。

**重要提示**：本技能辅助商务决策分析，不构成财务或法律意见。经济评估应结合实际业务数据由专业团队确认。

**独立能力（无需连接器）**

- 条款变动经济影响量化计算
- 风险-收益对照分析表
- 多情景测算（乐观/中性/悲观）
- 行业基准值对照（引用 [石油行业合同知识库](../石油行业合同知识库/SKILL.md)）
- 谈判决策建议

**增强能力（连接器加持）**

- ~~Notion -> 将经济影响分析发布到 Notion，便于管理层审阅

## 立场确认（每次调用必须执行）

**条款经济影响评估前必须先确认我方立场，立场决定经济计算视角和风险评估标准：**

使用 AskUserQuestion 工具向用户确认：

- **乙方/服务提供方**：我方提供录井、信息化、检测、一体化、导向等服务（计算重点：质保金压至5%的经济收益、验收拖延的资金占用损失、数据归属IP价值、甲方逾期付款违约金收益、停工期间固定成本）
- **甲方/委托方**：我方采购设备、租赁设备、委托外协服务（计算重点：供应商逾期交付的生产损失、质量不合格的返工成本、违约金覆盖度、租金封顶的经济收益、提前退租违约金、外协方擅自转包的风险敞口）
- **平衡型**：双方经济影响均衡评估

**立场与合同类型的典型对应关系（仅供参考，最终以用户确认为准）：**

| 合同类型 | 常见立场 | 说明 |
|---------|---------|------|
| 地质录井 / 钻试修信息化 / 检测分析 / 一体化 / 导向 | 乙方 | 计算服务方经济损失/收益 |
| 采购设备/物资 | 甲方 | 计算采购方经济损失/收益 |
| 设备(钻具)租赁 | 甲方（承租方） | 计算承租方经济损失/收益 |
| 委托外协服务 | 甲方 | 计算委托方经济损失/收益 |

**立场确认后，后续所有经济计算、行业基准对照、风险-收益分析均基于该立场执行。**

## 输入要求

1. **条款变更描述**：哪个条款、从什么内容变为什么内容
2. **合同金额量级**：合同总额、单价等（影响经济损失计算基数）
3. **合同期限**：合同期限长度（影响累计损失计算）
4. **评估情景**（可选）：乐观/中性/悲观（默认三情景均算）

## 执行流程

### 第一步：识别条款类型与影响维度

根据条款变更内容，确定影响维度：

| 条款类型 | 主要经济影响维度 |
|---------|----------------|
| **违约金条款** | 直接经济损失（违约金金额）+ 间接损失（停工成本） |
| **付款条款** | 资金占用成本 + 现金流影响 + 利息损失 |
| **钻具损坏赔偿** | 重置成本 + 折旧差异 + 停工损失 |
| **工期条款** | 延期成本（日运营成本）+ 提前完工收益 |
| **保险条款** | 保费支出 + 未覆盖风险敞口 |
| **停工费用条款** | 停工期间固定成本 + 人员基本工资 + 设备折旧 |
| **HSE条款** | 事故经济损失（估算）+ 合规处罚风险 |
| **知识产权条款** | 技术成果价值（估算）+ 数据资产价值 |

### 第二步：量化计算经济损失/收益

**计算框架**：

对每个条款变动，按以下框架量化：

1. **基准情景**：条款变更前的经济状态
2. **变更情景**：条款变更后的经济状态
3. **经济差异**：变更情景 - 基准情景 = 经济影响值

**三情景测算**：

| 情景 | 假设条件 | 计算结果 |
|------|---------|---------|
| **乐观** | 变动条款对我方最有利的场景 | [经济影响值] |
| **中性** | 最可能发生的场景 | [经济影响值] |
| **悲观** | 变动条款对我方最不利的场景 | [经济影响值] |

**服务方常见经济影响计算示例（乙方视角）**：

**质保金条款变更（我方核心关注）**：
- 原方案：质保金10%，质保期12个月
- 变更方案：质保金5%，质保期3个月（我方争取方案）
- 经济影响 = 合同总额 × (10% - 5%) = 合同总额 × 5%
- 示例：合同总额30万 → 质保金减少1.5万（资金提前回收）

**验收标准变更（主观→量化）**：
- 原方案：验收标准为"甲方认可"
- 变更方案：验收标准量化（覆盖率≥95%、符合率≥85%）+默示验收条款
- 经济影响 = 预估甲方拖延验收天数 × 日资金占用成本
- 示例：甲方拖延验收30天 × 合同总额30万 × 日利率万分之三 ≈ 2700元（主观验收风险）

**数据归属条款变更**：
- 原方案："所有数据和成果归甲方"
- 变更方案："原始数据归甲方，解释成果和算法归乙方"
- 经济影响 = 解释算法/模型的商业价值（估算）+ 未来项目复用价值
- 示例：解释算法商业价值估算50-100万（可复用于未来项目）

**甲方逾期付款**：
- 原方案：无逾期付款违约金
- 变更方案：逾期付款违约金万分之五/日
- 经济影响 = 合同总额 × 万分之五 × 预计逾期天数
- 示例：合同总额30万 × 0.05% × 30天 = 4500元

**甲方场景常见经济影响计算示例（甲方/委托方视角）**：

**供应商逾期交付（甲方核心关注）**：
- 原方案：无逾期交付违约金
- 变更方案：逾期交付违约金万分之五/日 + 阶梯递增
- 经济影响 = 逾期天数 × 日生产损失 + 违约金覆盖度
- 示例：逾期15天 × 日生产损失2万/天 = 30万，违约金覆盖 = 合同总额100万 × 0.05% × 15天 = 7500元（违约金远不能覆盖生产损失）

**设备质量不合格返工成本**：
- 原方案：质量标准笼统"符合甲方要求"
- 变更方案：明确引用国标编号 + 不合格无条件退换 + 供应商承担返工费用
- 经济影响 = 返工成本 + 延误损失 - 供应商赔偿覆盖度
- 示例：设备返工15天 × 日损失2万 = 30万，供应商赔偿 = 合同总额 × 20% = 20万（覆盖不足，缺口10万）

**租金封顶经济收益（承租方视角）**：
- 原方案：出租方有权随时调价
- 变更方案：年涨幅封顶5%或固定不涨
- 经济影响 = (无封顶预估涨幅 - 5%) × 年租金 × 合同年限
- 示例：预估年均涨幅10%，封顶5%，年租金50万，合同3年 → (10%-5%) × 50万 × 3年 = 7.5万（租金可控收益）

**外协方擅自转包风险敞口**：
- 原方案：无禁止转包条款
- 变更方案：禁止转包 = 根本违约 + 可立即解除 + 违约金20%
- 经济影响 = 转包质量损失 + 项目延误损失 + 知识产权泄露风险
- 示例：转包导致质量下降返工30万 + 延误20天 × 2万/天 = 40万 + 违约金覆盖20万 × 20% = 4万（风险敞口巨大，禁止转包条款至关重要）

### 第三步：行业基准对照

将计算结果与行业惯例基准对照（引用 [石油行业合同知识库](../石油行业合同知识库/SKILL.md)）：

| 评估项 | 我方计算结果 | 行业基准值 | 偏离度 | 偏离判定 |
|-------|-----------|----------|-------|---------|
| 钻具损坏赔偿标准 | [我方方案] | 折旧后价值60%-80% | [偏离%] | 合理/偏高/偏低 |
| 停工费用承担 | [我方方案] | 仅付人员基本工资+折旧 | [偏离%] | 合理/偏高/偏低 |
| 违约金比例 | [我方方案] | 万分之三/日（乙方争取）vs 万分之五/日（甲方常见） | [偏离%] | 合理/偏高/偏低 |
| 付款比例 | [我方方案] | 预付40%+完工55%+质保金5%（乙方争取） | [偏离%] | 合理/偏低 |
| 质保金 | [我方方案] | 5%（乙方争取）vs 10%（甲方常见） | [偏离%] | 偏高/合理 |
| 数据成果归属 | [我方方案] | 原始数据归甲方+成果归乙方 | [偏离%] | 偏向甲方/合理 |

### 第四步：风险-收益对照分析

生成风险-收益对照表：

| 条款变更 | 我方风险增量 | 我方收益增量 | 风险-收益比率 | 判定 |
|---------|------------|------------|------------|------|
| [条款A] | [损失金额] | [收益金额] | [比率] | 不利/可接受/有利 |
| [条款B] | [损失金额] | [收益金额] | [比率] | 不利/可接受/有利 |

**判定标准**：
- 风险增量 > 收益增量 3倍以上 → 不利，建议拒绝
- 风险增量 < 收益增量 → 有利，建议接受
- 风险增量 ≈ 收益增量 → 可接受，需结合其他条款综合判断

### 第五步：综合评估与谈判建议

**综合评估**：
- 所有条款变更的总经济影响 = 各条款经济影响之和
- 最不利情景的总经济损失
- 是否存在"小条款大损失"的情况（看似微小的条款变更可能带来重大经济损失）

**谈判建议**：
- 坚决拒绝的条款（经济损失超过阈值）
- 可以接受但有条件的条款（需设定上限/底线）
- 可以作为谈判筹码的条款（经济影响小但对方重视）

**阈值建议**（基于行业惯例）：
- 经济损失超过合同总额5% → 坚决拒绝
- 经济损失在合同总额1%-5% → 需谈判争取
- 经济损失低于合同总额1% → 可作为谈判筹码

## 质量标准

- 经济影响计算必须有明确的计算公式和假设条件
- 三情景测算必须覆盖乐观/中性/悲观三种可能
- 行业基准对照必须引用 [石油行业合同知识库](../石油行业合同知识库/SKILL.md) 的惯例参数
- 风险-收益对照必须量化，不得使用模糊表述
- 谈判建议必须基于经济计算结果，不得脱离数据
- 偏离度计算必须使用百分比，便于直观判断
- 合同总额占比计算必须准确（经济影响/合同总额×100%）
- 石油行业特有经济影响（停工、钻具损坏、井场事故）必须专项计算

## 关联技能

- **审查合同** -- 审查条款风险等级，作为经济评估的输入
- **合同对比** -- 对比两版合同条款差异，识别需评估经济影响的变更
- **谈判备忘整理** -- 经济评估结果可作为谈判备忘的依据
- **合规性检查** -- 不合规条款的行政处罚也是经济损失的一部分
- **石油行业合同知识库** -- 查阅行业惯例基准值用于对照
