# 内网资料调研模式

本模式用于基于用户提供文件、单位内网导出物和已归档标准，形成油田信息化调研材料。它不执行公网搜索，也不根据记忆补写供应商、价格、案例或标准现状。

## 输入

- 调研主题、决策目的和范围
- 本地资料目录或明确文件清单
- 时间边界、适用单位和版本日期
- 用户希望验证的假设

## 方法

1. 建立资料台账：文件、日期、发布单位、适用范围、证据位置。
2. 按“标准与正式制度、内部项目材料、检测或验收记录、供应商材料、未确认口述信息”分级。
3. 将每个结论绑定到文件与页码、章节或表格位置。
4. 对缺失的价格、性能、案例和现行性标记 `待补充/待人工确认`。
5. 输出结论、选项比较、风险、待补证据和下一步内部核验清单。

## 禁止事项

- 不访问搜索引擎、GitHub、供应商官网或社交媒体。
- 不把宣传材料当作独立验证。
- 不虚构市场份额、部署案例、标准状态或报价。
