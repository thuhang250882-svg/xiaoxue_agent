# /审查合同 -- 合同风险审查（石油行业定制版）

> 如遇到不熟悉的占位符或需检查已连接工具，参见 [CONNECTORS.md](../../CONNECTORS.md)。

对合同进行逐条风险审查，标记偏差，生成修改建议和谈判策略。针对石油钻探/地质录井行业提供专属审查重点。

**重要提示**：本技能辅助法律工作流程，不构成法律意见。所有分析结果应经执业律师审核后方可作为决策依据。

**独立能力（无需连接器）**

- 12类条款逐条审查 + 石油行业4类合同专属审查重点
- 红黄绿三级风险标记
- 具体替代条款措辞（非方向性建议）
- 三梯队谈判策略排序
- 缺失条款检测（含石油行业特有缺失条款）
- HSE安全条款专项审查
- 引用 [石油行业合同知识库](../石油行业合同知识库/SKILL.md) 提供行业惯例参数

**增强能力（连接器加持）**

## 立场确认（每次调用必须执行）

**审查合同前必须先确认我方立场，立场决定审查方向和风险判断标准：**

使用 AskUserQuestion 工具向用户确认：

- **乙方/服务提供方**：我方提供录井、信息化、检测、一体化、导向等服务（审查重点：甲方条款陷阱、验收主观化、质保金过高、知识产权全归甲方）
- **甲方/委托方**：我方采购设备、租赁设备、委托外协服务（审查重点：供应商履约保障、质量验收把控、违约惩罚力度、交付时限约束）
- **平衡型**：双方立场均衡审查

**立场与合同类型的典型对应关系（仅供参考，最终以用户确认为准）：**

| 合同类型 | 常见立场 | 说明 |
|---------|---------|------|
| 地质录井 / 钻试修信息化 / 检测分析 / 一体化 / 导向 | 乙方 | 我方提供服务 |
| 采购设备/物资 | 甲方 | 我方采购 |
| 设备(钻具)租赁 | 甲方（承租方） | 我方租用设备 |
| 委托外协服务 | 甲方 | 我方委托分包 |
| 技术开发 | 视情况 | 可为委托方或开发方 |

**立场确认后，后续所有审查逻辑、风险标记标准、谈判策略均基于该立场执行。**

## 输入要求

1. **我方立场**：[由立场确认步骤确定] — 乙方/服务提供方 / 甲方/委托方 / 平衡型
2. **合同类型**：地质录井 / 钻试修现场信息化 / 试验检测与解释分析 / 地质工程一体化 / 地质导向 / 设备(钻具)租赁 / 采购设备/物资 / 委托外协服务 / 技术开发 / 其他
3. **关注重点**（可选）：如"数据归属是核心问题"、"验收标准太主观"、"质保金太高"、"供应商交付保障不够"
4. **交易背景**（可选）：合同金额量级、井区/区块信息、合同工期、是否长期合作

用户只提供部分信息也可继续，标注假设条件。

## 执行流程

### 第一步：识别合同基本信息

提取：合同类型、签约双方（含统一社会信用代码如有）、签约日期、合同期限、合同标的（含井区/区块/井号如有）、合同金额。

**石油行业特有信息提取**：井区/区块编号、开钻日/完钻日约定、HSE条款是否独立成章、钻具/设备清单及价值、驻井人员数量与工种。

### 第二步：签约方背景核查

提示用户自行核实对方主体资格，标注"[建议通过企查查/天眼查核实签约方主体状态]"。

如用户提供了对方工商信息：
- 确认主体真实存续
- 如对方存在重大风险信号（已注销、被列为失信被执行人、大量诉讼），在报告开头予以警示
- **石油行业额外检查**：对方是否具有相应资质（钻井企业资质、录井企业资质等），是否持有安全生产许可证

### 第三步：加载合同类型专属审查重点

不同合同类型的审查侧重差异显著，按类型加载专属审查焦点：

| 合同类型 | 必审重点（Top 3） | 常见陷阱（按立场区分） |
|---------|-----------------|------------|
| **地质录井** | 数据成果归属、验收标准量化、驻井人员管理权 | 乙方：甲方要求"所有数据和成果归甲方"、验收用"甲方认可"、驻井人员服从甲方管理 |
| **钻试修现场信息化** | 软件知识产权、系统运维边界、数据安全归属 | 乙方：系统运维含非乙方系统、所有数据及系统归甲方、运维无上限 |
| **试验检测与解释分析** | 检测结论免责范围、报告用途限制、解释成果归属 | 乙方：检测结论被扩大至全井评价、报告用途无限制 |
| **地质工程一体化** | 知识产权（模型/算法）、各专业责任独立性、项目变更CCB | 乙方：全部成果含算法归甲方、连带责任、变更不加价 |
| **地质导向** | 导向决策责任、轨迹精度验收量化、实时数据传输 | 乙方：甲方按乙方建议执行后追责乙方、轨迹验收主观化 |
| **采购设备/物资** | 验收标准、质保期、付款条件 | 甲方：默示验收陷阱、质量举证责任倒置、逾期交付违约金不足 |
| **设备/钻具租赁** | 钻具完好率保证、租金调整机制、归还标准 | 甲方（承租方）：租金单方上涨、正常磨损被认定为损坏、提前退租罚金过高 |
| **委托外协服务** | 服务质量验收、知识产权归属、违约惩罚力度 | 甲方：验收标准模糊、外协方知识产权主张过强、违约金过低无法约束 |
| **HSE安全协议** | 安全责任划分、事故报告与处置流程、保险要求 | 甲方：外协方安全管理责任不清晰、保险覆盖不足 |
| **技术开发** | 知识产权归属、源代码交付、验收程序 | 视立场：委托方关注IP归委托方+交付完整；开发方关注IP归开发方+合理付款 |

### 第四步：逐条审查

基于内置知识引用核心法条，标注"[建议核实原文]"。同时引用 [石油行业合同知识库](../石油行业合同知识库/SKILL.md) 的行业惯例参数。

通读全文后，按以下审查表逐条分析。条款之间存在联动关系（如违约金与损害赔偿互相影响），需整体评估风险分配的合理性。

| 条款类别 | 审查要点 |
|---------|---------|
| **合同主体** | 签约主体资格、是否需要授权委托书、关联关系披露、**石油行业：是否持有安全生产许可证、钻井/录井资质** |
| **标的与范围** | 标的物/服务内容是否明确、验收标准、交付条件、**石油行业：井区/区块/井号是否明确、钻具清单是否完整、录井数据范围是否界定** |
| **价款与支付** | 付款条件、付款节点、发票类型、含税/不含税、逾期付款违约金、**石油行业：按进尺/按日/按月计费方式是否明确、停工期间费用承担** |
| **违约责任** | 违约金上限（参照第585条）、损害赔偿范围、免责条款、**石油行业：钻具损坏赔偿标准是否区分正常磨损与人为损坏、井场事故责任划分** |
| **知识产权** | 背景IP归属、新产生IP归属（第847/848条）、**核心关注：解释成果、解释算法、地质模型、分析软件归属——争取归我方或共同共有** |
| **保密条款** | 保密范围、期限、例外情形、违约救济、**石油行业：地质数据/储量信息的保密等级** |
| **不可抗力** | 定义范围、通知义务、后果处理、**石油行业：极端天气/地质条件复杂是否纳入、政府征用井场是否纳入** |
| **HSE条款** | **石油行业专项**：安全责任划分、事故报告流程、应急处理机制、保险覆盖、安全培训要求、**安全生产法合规性** |
| **争议解决** | 约定管辖vs法定管辖、仲裁条款有效性、适用法律 |
| **合同期限** | 期限起算、续约条件、提前终止权、到期后义务存续、**石油行业：开钻日/完钻日约定、续钻/完井条件** |
| **担保与保证** | 保证金/质保金、担保方式、保证人资格、**石油行业：钻具完好率保证、录井准确率保证** |
| **转让与变更** | 转让限制、变更程序、通知义务 |

**缺失条款检测**——除审查现有条款外，还须检查应有但缺失的关键条款：

| 应有条款 | 缺失后果 | 适用合同类型 |
|---------|---------|------------|
| 通知送达条款 | 无法证明通知已送达，影响解除权行使 | 所有类型 |
| 完整协议条款 | 口头承诺可能被主张为合同内容 | 所有类型 |
| 不可抗力条款 | 适用法定规则，可能不符合商业预期 | 所有类型 |
| **知识产权分层归属条款** | **原始数据vs解释成果vs算法模型归属不明** | **录井/信息化/检测/一体化/导向** |
| **验收标准量化条款** | **"甲方认可"导致验收无客观标准** | **录井/信息化/检测/一体化/导向** |
| **甲方配合义务条款** | **甲方不提供食宿/数据接口导致我方服务受阻** | **录井/信息化/一体化/导向** |
| **服务范围锁定条款** | **甲方超范围要求但不加价** | **录井/信息化/一体化/导向** |
| **导向决策责任条款** | **乙方建议vs甲方决策责任不清** | **地质导向** |
| **检测结论免责条款** | **检测结论被扩大至全井评价** | **检测分析** |
| **系统运维边界条款** | **运维责任含非乙方系统** | **信息化** |
| HSE安全条款 | 井场事故责任无法界定 | 驻井服务类 |
| 保险条款 | 井场人员/设备保险覆盖不足 | 驻井服务类 |

### 第五步：标记风险等级

**通过（绿色）**——条款合理，无需修改。

**需改（黄色）**——条款偏离我方理想立场但可谈判。
必须输出：原文引用 + 替代条款措辞 + 修改理由 + 退让底线。

**需谈（红色）**——重大风险或严重偏离法律规定。
必须输出：具体风险描述 + 法律依据 + 可能的经济/法律后果 + 谈判策略或替代方案。

**违约金合理性量化校验**（适用于所有包含违约金的条款）：

| 校验项 | 安全区间 | 风险阈值 | 法律依据 |
|-------|---------|---------|---------|
| 逾期违约金（日） | 万分之三至万分之五 | 超过万分之五有被调减风险 | 第585条+通则解释第64条 |
| 根本违约金 | 合同总价10%-20% | 超过30%可能被调减 | 超过实际损失30%的部分 |
| 定金 | 不超过主合同标的额20% | 超过20%部分不生效 | 第586条硬性上限 |
| 对方违约金vs我方违约金 | 比例对等 | 差距>2倍视为不公平 | 公平原则 |
| **钻具损坏赔偿** | **重置价60%-80%（扣除折旧）** | **按全新重置价100%赔偿** | **公平原则+折旧惯例** |
| **停工期间费用** | **仅付人员基本工资+设备折旧** | **全额日租金/月租金照付** | **公平原则+行业惯例** |

### 第六步：生成谈判策略

按优先级组织修改建议：

- **第一梯队（必须争取）**：涉及合同效力、重大经济风险、法律强制性规定的条款，**以及HSE安全责任划分条款**
- **第二梯队（重点争取）**：影响权利义务平衡但有谈判空间的条款
- **第三梯队（可以让步）**：改善我方地位但非关键的条款，可作为谈判筹码

## 质量标准

- 每项审查意见必须引用具体法条或司法解释条文
- 修改建议必须提供具体替代条款措辞，非笼统方向性建议
- 风险等级判定必须有明确理由
- 违约金审查必须按量化校验规则检查合理性
- 不得引用外国法律作为主要依据
- 仲裁条款必须检查有效性三要素（仲裁意思表示、仲裁事项、仲裁机构）
- 缺失条款检测必须覆盖，不能只审查现有条款
- 双方违约责任对等性必须检查
- **石油行业合同必须检查HSE条款完整性**
- **钻井/录井合同必须检查地质数据/知识产权归属**
- **设备/钻具租赁必须检查损坏赔偿标准是否区分正常磨损**

## 关联技能

- **合同对比** -- 如有对方修改的新版本，可对比两版差异
- **NDA快筛** -- 如合同中含有独立NDA或保密条款需要快速评估
- **法条速查** -- 深入了解特定条款涉及的法条细节
