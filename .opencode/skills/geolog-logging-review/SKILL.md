# 地质录井报告审核

## 目标

对真实报告包做可追溯审核。先建立文件清单和证据边界，再检查主报告、基础表、记录表、解释表和图件之间的一致性。不得因为文件能打开、章节齐全或文本表述通顺就判定通过。

## 输入与证据边界

1. 递归列出用户指定目录中的全部文件，不遗漏同井附件。
2. 名称含“录井报告”“完井报告”或“地质总结”的文件通常为主报告；其余成果表、记录表、卡片和图件为交叉校验依据。若有多个候选版本，列出版本、修改时间和文件类型，请用户确认或明确说明采用规则。
3. 读取 DOC/DOCX 的正文、表格、页眉页脚、文本框和批注；读取 PDF 的原生文本、页数并抽查渲染页；读取 XLS/XLSX 的工作表、单元格值和公式结果。
4. 纯文本提取不能证明分页、图片、图例、签字外观和版式正确。没有渲染证据时，位置写“章节/表名/字段/原文片段”，不得臆测页码。
5. 关键附件不可读、缺失或只有无法识别的图片时，将对应项目标记为“无法验证”，不得判为通过。

遇到整井资料包时，先读 [真实报告结构与资料映射](references/real-report-structure.md)。

## 审核流程

### 1. 建立资料清单

按以下类别分组：

- 主报告；
- 基础数据与完井卡片；
- 地层、岩性、取心与测井资料；
- 气测、地化、油气显示和解释成果；
- 工程、钻井液、地层压力、后效气和复杂情况；
- 套管、井身结构、附图与照片。

记录每个文件的格式、可读状态、包含的表名/工作表和可用证据。附件编号只能作为线索，必须按表名和字段语义匹配，不能假定不同文件中的“附表 2”是同一张表。

### 2. 运行确定性初检

若已获得文本提取结果，对一个或多个文本文件运行：

```powershell
python scripts/audit_extracted_text.py report.txt attachment.txt
```

该脚本只负责发现候选异常，包括模板残留、章节编号跳号、子节前缀错位、可疑深度反向、箭头数值方向、损坏单位和重复标点。所有命中都必须回到源文件和上下文复核，不能直接当作专业结论。

### 3. 格式与完整性审核

逐项执行 [报告格式检查清单](references/report-format-checklist.md)，重点检查：

- 封面、审批页、编制/审核/批准、日期和单位是否完整；
- 目录与正文标题是否一致，章节和附表附图编号是否连续；
- 是否残留 `XXXX`、`XX月XX日`、“待落实”、编辑说明、内部提醒或模板批注；
- 表头、单位、图例、页眉页脚、名称、井号和版本是否一致；
- 正文引用的每个附表、附图、附件是否实际存在且名称匹配。

### 4. 数据一致性与专业审核

按 [专业审核清单](references/professional-review-checklist.md) 建立“字段—来源—值—位置”对照表。至少核对：

- 井名、井别、坐标、构造位置、地面海拔、补心高、补心海拔、设计井深和完钻井深；
- 开钻、完钻、完井日期和钻井周期；
- 地层顶底界、层位代号、深度区间和厚度；
- 气测显示段的起止深度、全烃/组分基值与峰值、解释结论；
- 取心井段、进尺、心长、收获率和归位/校深前后关系；
- 钻井液密度、地层压力、工程事件、后效气和复杂情况；
- 正文结论与气测、地化、测井、岩屑/岩心显示证据是否相互支持。

计算值必须复算：`厚度 = 底深 - 顶深`，`收获率 = 心长 ÷ 进尺 × 100%`，`补心海拔 = 地面海拔 + 补心高`。允许的舍入误差应在输出中说明。

### 5. 复核异常并定级

参考 [常见问题与严重级别](references/common-issues.md)。对每个异常：

1. 引用源文件、章节/表名/字段和原值；
2. 给出对照来源及其值；
3. 说明校验关系或计算过程；
4. 区分“已确认错误”“高风险疑点”“需人工确认”“无法验证”；
5. 给出可执行修改建议，不擅自替用户改写地质结论。

## 输出格式

```markdown
# 地质录井报告审核结果

## 审核范围与证据状态
| 文件 | 角色 | 格式 | 读取状态 | 用途/限制 |

## 总体结论
- 结论：通过 / 修改后通过 / 退回修改 / 无法完成审核
- 严重问题：X 项；一般问题：X 项；提示项：X 项；无法验证：X 项

## 问题清单
| 序号 | 严重级别 | 状态 | 文件与位置 | 原值/原文 | 对照证据 | 校验说明 | 修改建议 |

## 关键数据对照
| 字段 | 主报告 | 附件/来源 | 结论 |

## 缺失资料与人工复核项

## 审核结论与签署建议
```

“通过”只用于：必需资料可读、严重问题为零、关键数据交叉核对完成、版式/图件项目已有相应视觉证据。否则选择“修改后通过”“退回修改”或“无法完成审核”。
