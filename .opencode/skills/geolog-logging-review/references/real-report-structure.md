# 真实报告结构与资料映射

## 常见主报告结构

真实录井报告通常包含：

1. 概况：基本数据、钻井简史、井位和设计任务；
2. 录井工作量及质量控制：录井项目、井段、比例、资料质量；
3. 工程录井：工程监测、地层压力、钻井液、复杂情况、时效统计；
4. 地层描述、储集层及油气水评价：地层、岩性、显示、气测、地化、测井和综合解释；
5. 结论、建议及认识；
6. 附表、附图和附件。

章节名称和顺序可因甲方模板不同而变化。审核时以语义和字段为准，同时检查目录与正文编号一致性。

## 资料包角色映射

| 资料类型 | 主要字段 | 应交叉核对的主报告位置 |
|---|---|---|
| 完井卡片/基本数据表 | 井名、井别、坐标、海拔、设计/完钻井深、日期 | 第一章基本数据、封面、结论 |
| 录井综合记录 | 地层、岩性、钻时、气测、工程事件 | 钻井简史、地层描述、显示评价 |
| 测井解释成果表 | 层位、井段、厚度、解释结论 | 储集层评价、综合解释、结论 |
| 气测解释成果表 | 显示井段、厚度、全烃、C1-C5、解释 | 气测异常、油气显示、综合解释 |
| 储集层地化解释成果表 | 井段、岩性、地化参数、解释 | 地化录井、储层与含油气性评价 |
| 油气显示解释表/统计表 | 层位、井段、显示级别、解释 | 油气显示综述、结论 |
| 取心描述/统计表 | 次数、井段、进尺、心长、收获率、归位 | 取心工作量、岩心描述、地层评价 |
| 地层压力/钻井液/后效气 | 深度、时间、密度、压力、峰值、事件 | 工程录井、压力监测、复杂情况 |
| 套管记录 | 套管程序、规格、下深、附件、累计长度 | 井身结构、钻井简史、完井数据 |
| 附图/照片 | 比例尺、图例、井段、标题、编号 | 正文图件引用、附件目录 |

附件序号在独立文件与汇编主报告中可能不同。以井名、表名、字段和数据内容联合匹配，不以“附表 N”单独连接。

## 来源优先级与冲突处理

不存在对所有字段都适用的单一“权威文件”。按字段记录来源：

- 原始记录/仪器数据用于证明观测值；
- 经签署的成果表用于证明解释成果；
- 完井卡片和审批后的基本数据表用于证明基础井信息；
- 主报告用于证明最终叙述和结论。

发现冲突时并列报告各来源，不自行选择一个值覆盖另一个值。只有当用户、签署状态、版本日期或明确制度给出优先级时，才能判定应采用哪个值。

## 必做连接键

- 井级：井名 + 井别；
- 层级：层位代号 + 顶深 + 底深；
- 显示层：层位 + 显示起止深度；
- 取心：取心次数 + 原始/归位井段；
- 工程事件：日期时间 + 井深 + 事件类型；
- 套管：开次/层次 + 外径 + 下深。

深度经过测井校深或岩心归位时，必须同时保存“原始值”和“校正后值”，并检查报告是否清楚说明转换关系。
