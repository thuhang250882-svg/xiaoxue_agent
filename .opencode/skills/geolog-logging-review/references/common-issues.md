# 常见问题与严重级别

## 严重问题

- 井名、坐标、完钻井深、关键地层界面或油气显示井段错误。
- 深度区间颠倒、录井范围超出完钻井深、厚度与起止深度明显不符。
- 主报告结论与签署成果表矛盾，且未解释采信依据。
- 最终稿仍有模板占位符、关键签署缺失或正文引用的关键附件缺失。
- 关键数据无法读取却仍给出“通过”结论。

## 一般问题

- 目录跳号、子节父级前缀错误、附表附图编号不连续。
- 同一字段小数位或舍入不一致但不改变解释结论。
- 表头、单位、页眉页脚、术语或井号局部不一致。
- 正文与附件存在可解释的校深差异，但报告未说明转换关系。

## 提示项

- 表述冗长、重复、标点或空格问题。
- 版式、图片清晰度、跨页表头等不影响数据含义的问题。
- 建议补充来源、标准版本或计算说明。

## 真实样本归纳出的高价值模式

以下模式用于建立规则，不应在审核其他井时机械套用具体数值：

- 邻近数据均指向约 6942 m，正文一处误成 3942 m：需要“区间合法性 + 附件对照”，普通拼写检查发现不了。
- 最终报告保留 `XXXX年XX月XX日`、“待落实”和编辑提醒：必须执行模板残留硬门禁。
- 目录从 3.2 跳到 3.4：检查编号连续性，并确认是否缺失 3.3。
- 父节 4.2.19 下出现 4.2.14.1：检查子节必须继承完整父级前缀。
- `g/cm?` 或粒径使用明显不合数量级的单位：区分编码损坏与专业单位错误。
- `a↑b` 但 `b < a`：复核箭头方向、列错位和原始记录；不能只因数值看似正常就忽略。

## 输出措辞

- 不写“数据有误”而无证据；写明原值、对照值和校验关系。
- 不把所有问题都定为严重；说明问题对井深、解释结论、签署或可追溯性的影响。
- 不直接替换有争议的专业结论；建议由对应责任人确认并重新签署。
