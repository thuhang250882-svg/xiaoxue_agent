# /桌面调研 -- 石油行业信息化桌面调研

**适用场景**：石油行业信息化规划、智能油田技术选型、录井技术产品调研、IT基础设施方案论证、供应商能力摸底、行业标准与政策梳理。

**核心能力**：
- 假设驱动的石油行业信息化调研框架
- 信息源可信度 Tier1-5 分级体系（油气行业专属数据源）
- 五种调研主题类型自动分支（技术/基础设施/供应商/标准/可行性）
- 三档深度自适应（快速扫描2000字 / 标准调研5000字 / 深度调研8000字+）
- 所有数据点强制标注来源与年份，不可验证项标注 [需验证]

## 调用方式

```
/桌面调研 <调研主题 + 调研目的>
```

## 输入要求

1. **调研主题**：智能油田技术 / IT基础设施 / 供应商产品 / 行业标准 / 技术方案可行性
2. **调研目的**：立项论证 / 技术选型 / 供应商入围筛选 / 合规整改 / 方案可行性评估
3. **深度要求**：快速扫描 / 标准调研 / 深度调研（未指定时默认标准调研）
4. **特别关注**：需重点回答的问题或需验证的假设
5. **已有材料**：可上传已有招标文件、技术方案、报价单、行业报告等
6. **地域范围**：新疆油田/塔里木油田/西部钻探作业区域/全国/国际

> 分支判断——深度选择：
> - 仅需了解技术概貌、为内部讨论做准备 → **快速扫描**（约2000字）
> - 为项目立项、技术选型提供背景支撑 → **标准调研**（约5000字）
> - 为重大投资决策、方案论证提供系统化证据 → **深度调研**（8000字+多框架）
> - 如用户未明确深度，默认按**标准调研**执行

## 信息源可信度分级（石油行业专属）

| 层级 | 来源类型 | 典型来源 | 可信度 | 引用规则 |
|------|---------|---------|--------|---------|
| **Tier 1** | 国家/企业标准与官方数据 | 国家标准(SY/T系列)、中石油企标(QSY系列)、各油田公司官方数据、工信部/能源局文件 | 最高 | 可直接引用，标注标准号+发布日期 |
| **Tier 2** | 行业权威技术期刊与出版物 | 《石油勘探与开发》、《测井技术》、《录井工程》、《石油工业技术监督》、石油工业出版社、中国石油学会论文集 | 高 | 可直接引用，标注期刊名+年份+期号 |
| **Tier 3** | 行业研究机构与厂商白皮书 | 中石油数字化转型研究中心、中石化信息技术研究院、华为/中兴油气行业白皮书、油田数字化专业媒体(如《数字石油和化工》) | 中高 | 可引用，建议与Tier1/Tier2交叉验证 |
| **Tier 4** | 行业媒体与技术论坛 | 中国石油报、中国石化报、CIPPE展会报道、石油信息化技术论坛、中国石油学会年会 | 中 | 需交叉验证，标注"据XX报道[需验证]" |
| **Tier 5** | 社交媒体与宣传材料 | 微信公众号、供应商官网宣传页、产品彩页、技术博客、行业微信群讨论 | 低 | 仅做定性参考，不可作为核心论据 |

> 注意：供应商自行发布的性能参数、价格信息属于Tier 5，用于初步筛选可以，但不可作为技术选型或价格论证的唯一依据。涉及关键决策时须要求供应商提供第三方检测报告或现场测试数据。

## 调研主题类型与分支逻辑

根据用户输入的调研主题，自动识别并进入对应的分析分支：

### 分支A：智能油田技术调研

**典型主题**：井场AI视频监控、录井数据实时采集传输、智能钻井参数优化、油藏数值模拟平台、边缘计算在井场的应用

**分析重点**：
1. **技术成熟度评估**：该技术处于实验室验证/试点应用/规模推广哪个阶段？国内油田有无成功部署案例？
2. **部署案例梳理**：哪些油田已部署？部署规模、运行效果、遇到的问题？
3. **供应商能力摸底**：国内主要供应商有哪些？各自技术路线、核心优势、市场份额？
4. **成本分析**：硬件/软件/实施/运维各环节成本构成，单井/区块/油田级别的投入估算
5. **适用性评估**：该技术对我方作业环境（如塔里木高温高压、西部戈壁恶劣条件）的适用性如何？

### 分支B：IT基础设施调研

**典型主题**：油田数据中心服务器选型、井场边缘计算设备、工业级网络设备、私有云/混合云架构、数据备份与灾备方案

**分析重点**：
1. **环境适应性**：设备是否满足油田现场环境要求（防爆等级Ex、温度范围-40~+70C、防尘防水IP65+、抗振动）
2. **性能指标**：处理能力、存储容量、网络带宽、延迟要求是否满足业务场景
3. **可靠性与冗余**：MTBF（平均无故障时间）、冗余设计、故障恢复时间
4. **信创合规**：是否在信创目录内、国产化率要求、涉密信息系统适配
5. **运维便利性**：远程运维能力、备件供应、现场技术支持响应时间

### 分支C：供应商/产品调研

**典型主题**：广陆/晴和井场信息化设备对比、AI视频监控厂商调研、录井仪供应商摸底、数据采集系统供应商评估

**分析重点**：
1. **功能对比**：核心功能清单、差异化特性、与现有系统的兼容性
2. **性能测试**：关键性能指标、第三方检测报告、现场测试数据
3. **价格对比**：设备单价、系统集成费、年度运维费、总体拥有成本(TCO)
4. **服务能力**：售后响应时间、现场服务覆盖范围、备品备件供应、培训支持
5. **案例参考**：中石油/中石化/中海油体系内的部署案例、用户反馈

### 分支D：行业标准/政策调研

**典型主题**：录井数据采集传输标准、油田数字化转型政策、网络安全等级保护要求、涉密信息系统管理规定

**分析重点**：
1. **适用范围**：该标准/政策适用于哪些场景？对我方业务有何约束？
2. **核心要求**：关键技术指标、合规要求、时间节点
3. **合规差距**：我方现状与标准要求的差距有多大？
4. **整改建议**：需要哪些整改措施？预估投入和时间表
5. **政策趋势**：标准/政策的演进方向，未来可能的变化

### 分支E：技术方案可行性调研

**典型主题**：井场物联网建设方案可行性、数据中心容灾方案论证、录井数据云平台建设可行性

**分析重点**：
1. **技术可行性**：技术方案是否成熟？关键技术瓶颈是什么？
2. **经济可行性**：投入产出比(ROI)、投资回收期、全生命周期成本
3. **实施可行性**：实施周期、资源需求、组织保障、风险因素
4. **风险评估**：技术风险、实施风险、运维风险、安全风险
5. **替代方案**：有无更优的替代方案？各方案优劣势对比

## 执行流程

### 第一步：界定调研范围

按以下维度明确调研边界，提出2-3个初始假设或关键问题：

| 维度 | 界定内容 | 示例 |
|------|---------|------|
| **地域范围** | 新疆油田/塔里木/全国/国际 | 聚焦西部钻探作业区域 |
| **技术范围** | 具体技术领域或产品类型 | 井场AI视频监控（不含后端平台） |
| **时间范围** | 关注近几年的技术发展和市场变化 | 近3年（2023-2026） |
| **供应商范围** | 需重点关注的供应商或全部摸底 | 广陆、晴和、海默科技等 |
| **业务场景** | 录井/钻井/测井/试油/数据中心 | 地质录井现场数据采集 |

**输出**：调研范围确认 + 关键问题清单（3-5个）+ 初始假设（如有）

> 注意：范围界定是调研质量的第一道防线。常见错误包括：范围过大导致蜻蜓点水（如"石油行业信息化"应缩窄到"录井数据实时采集传输技术方案"）、范围过小导致缺乏决策参考价值。

### 第二步：多源信息搜集

按 Tier1 → Tier2 → Tier3 → Tier4 优先级依次搜索，自动交叉验证多个来源的数据一致性。对所有搜索结果去重、按时效排序、标注数据年份。

**搜索策略**：
- **标准类信息**：优先搜索国家标准全文公开系统、中石油企标平台、能源局官网
- **技术类信息**：优先搜索CNKI论文、石油行业期刊、厂商技术白皮书
- **供应商信息**：优先搜索政府采购网中标公告、油田公司供应商名录、行业展会参展信息
- **价格信息**：优先搜索政府采购网历史成交价、招标平台报价、行业参考价

**数据时效标注规则**：
- 所有引用数据必须标注年份
- 超过2年的技术标准须检查是否有更新版本
- 超过1年的价格数据须标注"[价格年份：20XX，建议询价更新]"
- 不同来源的同一指标差异>30%时须特别说明

### 第三步：分析整理

根据调研主题类型（见上方分支逻辑），选择对应的分析路径：

**技术调研分析链**：
```
技术成熟度评估 → 国内部署案例梳理 → 成本结构分析 → 我方适用性评估 → 建议与风险提示
```

**供应商调研分析链**：
```
供应商清单初筛 → 功能/性能对比矩阵 → 价格对比（TCO） → 服务能力评估 → 案例参考验证 → 综合推荐
```

**标准调研分析链**：
```
标准适用范围确认 → 核心技术要求提取 → 我方合规差距分析 → 整改建议与路线图 → 政策趋势研判
```

**可行性调研分析链**：
```
技术可行性论证 → 经济可行性分析(ROI) → 实施可行性评估 → 风险识别与应对 → 替代方案对比 → 综合建议
```

**每个分析环节结束时须回答"So What"**：这个发现对我们的决策意味着什么？

## 质量标准

- **来源标注**：每个定量数据点必须标注来源和年份，或标注[需验证]
- **可信度分级**：来源须按Tier1-Tier5分级标注，核心结论不可仅依赖Tier4-Tier5来源
- **交叉验证**：关键数据（价格、性能指标、市场份额）须至少2个来源交叉验证
- **假设驱动**：围绕关键问题展开分析，而非漫无目的罗列信息
- **So What检验**：每个关键发现必须回答"这对我们的决策意味着什么"
- **时效标注**：所有数据标注年份，超过2年的标准须确认是否现行有效
- **可操作性**：知识缺口须给出具体补充路径（找谁问、查什么库、看什么报告）
- **场景适配**：分析须结合我方实际作业环境（西部戈壁、高温高压、远程井场等）

## 红线规则

1. **绝不编造数据**：任何定量数据（价格、性能参数、市场份额）必须有明确来源，无法确认的标注[需验证]，严禁杜撰
2. **绝不虚构产品/供应商**：不可编造不存在的产品型号、供应商名称或技术参数
3. **绝不伪造标准文件**：不可编造不存在的标准编号、政策文件或技术规范
4. **Tier5来源不可支撑核心结论**：供应商宣传材料、社交媒体信息仅供初步参考
5. **不隐藏数据缺口**：信息不足时如实标注，不以模糊表述掩盖数据缺失
6. **不做预测性承诺**：成本估算和技术效果是"基于假设的估算"，不可表述为"确定能达到"
7. **超出能力范围须转介**：涉及防爆认证、网络安全等保、涉密系统等专业领域，须建议用户咨询专业机构

## 灰色地带处理

1. **不同来源数据矛盾**：并列展示各来源数据，分析差异原因（统计口径不同、测试条件不同、产品版本不同），给出判断并标注"[分析师判断，建议验证]"
2. **供应商数据不可获取**：非上市供应商的财务数据、市场份额通常无法公开获取。此时应标注[数据不可获取]，建议通过招标平台历史成交价、行业知情人士或专家访谈等渠道补充
3. **新技术无部署案例**：对于极早期技术，应以技术原理分析、实验室数据、类似场景应用案例替代油田实际部署数据，并标注"[尚无油田规模部署案例，结论仅供参考]"
4. **价格信息时效性**：IT设备价格波动较大，超过6个月的价格数据须标注"[价格年份：20XX，建议重新询价]"，芯片/服务器类产品价格下降趋势明显

## 输入不足处理

- 仅提供调研主题时：输出快速扫描版（~2000字），标注"信息有限，建议补充调研目的和深度要求"
- 缺少关键信息时：主动追问调研目的、深度要求、特别关注领域
- 绝不编造数据、案例或供应商信息——无法验证的信息标注[需验证]
- **快速模式**：用户信息充足且深度明确 → 直接执行
- **引导模式**：用户仅给出模糊主题 → 先输出快速扫描，同时追问关键参数

## Agent 工具增强

- **WebSearch**：搜索石油行业标准、技术期刊、供应商信息、政府采购数据，按Tier优先级搜索
- **文件处理**：支持读取用户上传的技术方案PDF、招标文档、报价单、行业报告等
- **代码执行**：成本测算、TCO计算、性能指标对比等使用Python确保计算精度
- **图像识别**：可解读用户上传的技术架构图、产品参数截图、招标公示截图等
