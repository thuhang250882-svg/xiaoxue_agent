# 办公网离线适配（本技能的执行前提）

> 本技能运行于「录井小雪」办公网本地 profile（`network_policy: office_network_local_only`）。
> **执行任何涉及联网、外部 API、安装依赖的动作前，先读本文件。**

## 一、总原则

| 策略项 | 取值 |
|---|---|
| 网络策略 | `office_network_local_only` —— 仅本地/单位内网 |
| 外部网络技能 | `disabled_and_removed` —— 禁用并移除 |
| GitHub 依赖 | `disabled_and_removed` —— 禁用并移除 |
| 本地脚本 | 允许，受既有权限规则约束 |
| 单位内网资料 | 仅在用户授权后允许访问 |

据此，本技能的一切能力必须能在**完全断网**条件下工作。

## 二、原能力域的降级对照

| 编号 | 原始能力 | 办公网可用性 | 处置 |
|---|---|---|---|
| C1 | 论文写作与润色 | 完全可用 | 保持 |
| C2 | 文献阅读与报告 | 完全可用 | 输入限定为用户本地提供的文献 |
| C3 | 科学计算与数据分析 | 部分可用 | 仅 Python；MATLAB 视本地安装情况，不得假定存在 |
| C4 | 学术文档与幻灯片生成 | 完全可用 | 保持 |
| C5 | 文献检索与引用管理 | **降级** | 联网检索全部移除，改为本地解析与核验（见 `evidence-and-citation.md`） |
| C6 | 可复现研究规范 | 完全可用 | 保持 |

## 三、禁止行为清单

1. 不调用任何文献数据库或 DOI 解析接口。
2. 不下载文献全文、数据集、模型权重、依赖包。
3. 不访问 GitHub 或任何代码托管平台获取资源。
4. 不向任何外部服务发送研究数据、稿件内容或用户信息。
5. 不因缺少某个包/工具而尝试联网安装；应改为使用本地已有能力或降级方案。

## 四、能力缺失时的处置

当用户请求落在离线不可用的能力上（例如"帮我检索这个方向的文献"）：

1. **明说不可用** —— 直接告知该能力在当前环境未提供，说明原因（办公网策略）。
2. **给替代路径** —— 提供可在本地完成的等价流程。例如：
   - 请用户提供 PDF 或参考文献清单 → 本地解析、结构化、核验。
   - 请用户提供已有资料 → 本地提炼与标注。
3. **绝不降级为编造** —— 不得因无法检索就生成看起来合理的文献条目、DOI 或数值。

## 五、依赖与运行环境

- 优先使用环境已内置的 Python 运行时与已安装依赖。
- 使用前先用最小命令实测关键依赖是否可用。
- 运行环境信息（解释器版本、依赖版本、执行命令）随产出报告。
- 中文字体可用性需实测；缺失时回退到英文字形并告知用户，不静默降级。

## 六、数据边界

- 只处理用户明确提供的本地文件与授权的单位内网材料。
- 不主动扫描用户目录寻找"可能有用的资料"。
- 产出文件另存为带版本标记的新文件，不覆盖原件。
