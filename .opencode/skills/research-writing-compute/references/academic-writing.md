# C1/C2 · 学术写作与文献阅读

## 一、论文写作与润色（C1）

### 章节覆盖

摘要、引言、相关工作、方法、实验、结果讨论、结论。各章节的写作重心：

| 章节 | 必须回答的问题 |
|---|---|
| 摘要 | 做了什么、怎么做、结果如何、有何意义（四要素齐全，不写背景铺垫） |
| 引言 | 问题是什么、为什么重要、已有工作到哪一步、缺什么、本文补什么 |
| 相关工作 | 与本文最接近的几条路线分别进展、各自局限、本文与之的差异 |
| 方法 | 输入是什么、每一步做什么、为什么这样做、关键假设与参数 |
| 实验 | 数据集、评价指标、对比基线、实验设置（可复现所需信息） |
| 结果讨论 | 结果支持了什么结论、与预期不符之处、失败案例与原因 |
| 结论 | 贡献复述、局限、未来工作 |

### 三种工作模式

**生成式**（从模糊想法到成稿）

1. 先产出论证蓝图，不直接写正文。蓝图六要素：问题 → 差距 → 方法 → 证据 → 贡献 → 局限。
2. 蓝图经用户确认后，再逐章节成稿。
3. 章节顺序默认按逻辑依赖推进，不按论文物理顺序。

**修订式**（对已有稿件）

三重检查，逐项给出问题定位与改法：

- **逻辑**：论点是否有证据支撑、章节间是否跳跃、结论是否超出证据范围。
- **术语一致性**：同一概念是否换词、缩写首次出现是否给全称、符号是否前后冲突。
- **引用准确性**：论断是否确实由所引文献支撑、引用位置是否恰当、是否存在无出处的定量表述。

**审查式**（读者视角通读）

以审稿人视角列出问题清单，按严重程度分级，不直接改稿。

### 输出纪律

- 修订稿中标注**段落角色**，例如「引言·研究缺口」。
- 涉及指标或对比数据一律用 Markdown 表格。
- 每章先给 3–7 条大纲，再展开正文。

## 二、文献阅读与报告（C2）

### 输入

PDF / 论文 / 稿件（可能多篇）。办公网环境下全部来自用户本地提供。

### 核心机制：来源映射

对报告中每一条实质性信息，追溯到"哪篇文献、哪个位置"。来源映射的粒度到段落或图表级，不到整篇。

### 四类信息分级

阅读报告中所有内容必须归入以下四类之一并加标签：

| 标签 | 判定标准 |
|---|---|
| 论文原文 | 原句或原意直述，可指出所在位置 |
| 图表证据 | 数值来自文中图表，可指出图表编号 |
| 上下文推断 | 由多处信息综合推理得出，原文未直述 |
| 建议 | 助手给出的延伸意见，无文献证据属性 |

不允许出现"无标签"的实质性论断。

### 输出形态

- 结构化文献阅读报告（中文；用户要求时中英双语）。
- 报告结构：研究问题 → 方法 → 数据与实验 → 主要结论 → 局限 → 与用户课题的关系（标注为"建议"）。
- 需要时派生为报告幻灯片（见 `academic-deliverables.md`）。

### 禁止

- 不编造文献的出版信息、作者、年份、卷期页码、DOI。
- 元数据缺失时标记「未在原文中明确给出」，不推断填充。
