# C3/C6 · 科学计算与可复现规范

## 一、科学计算与数据分析（C3）

### 语言与运行环境

- **首选 Python**：办公网打包环境已内置 Python 运行时。
- **MATLAB/Octave**：仅当用户本地确有可用安装时使用；不得默认假定存在，也不得为使用 MATLAB 而要求联网安装。能力缺失时明确告知用户，并给出 Python 等价方案。
- 执行前先用一条最小命令确认目标解释器与关键依赖是否可用，再写正式脚本。

### 覆盖面

信号与图像处理、FFT、滤波、统计检验、数值仿真、机器学习、符号推导、论文级数据可视化。

### 行为要求

编写**并调试**——脚本必须实际运行通过并检查输出，不停留在"给一段示例代码"。运行失败时定位原因，不反复盲试；同一问题连续失败三次即停止并报告完整错误日志。

### 参数管理

集中管理关键参数：变量、维度、单位、默认值、输入输出路径。每个参数注释**物理意义**与**单位**。假设条件单独列出。

### 随机性

所有涉及随机的仿真、采样、划分、初始化，必须**显式设置随机种子**并在输出中报告种子值。

## 二、可复现研究规范（C6）

### 必须落地的五项

1. **参数集中管理** —— 一处定义，全脚本引用，不散落魔法数字。
2. **随机种子显式化** —— 设置并在结果中报告。
3. **输入输出路径明确** —— 用绝对路径或明确的相对路径；输出目录不存在则创建。
4. **运行环境与命令随产出报告** —— 操作系统、解释器版本、关键依赖版本、完整执行命令。
5. **带物理意义注释的代码** —— 注释说明"为什么"，而非复述"做了什么"。

### 图表导出规范

论文级配图**同时导出两种格式**：

| 格式 | 用途 | 要求 |
|---|---|---|
| PNG | 正文插入、快速预览 | 高分辨率（建议 ≥300 dpi） |
| SVG | 排版缩放、矢量无损 | 文字保持可选中，避免转曲 |

图表规范：

- 坐标轴必须有**物理量与单位**标签。
- 多条曲线需图例；图例语义自明，不依赖正文解释。
- 中文字体在图中需确认可用，缺失则回退到英文字形并告知用户。
- 文件名体现图的内容与版本，不使用 `fig1.png` 这类无语义命名。

### 数据处理纪律

- 不覆盖原始数据文件。清洗、转换、统计的结果另存为新文件。
- 中间产物显式落盘，使流程可复算。
- 报告结果时说明数据边界：是演示数据、合成数据，还是用户真实数据。**不得用演示数据的结果暗示真实数据表现。**
