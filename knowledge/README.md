# 录井小雪企业知识库

本目录保存可供录井小雪检索、引用和审核辅助使用的企业知识资产。当前仅建立目录与来源约束，后续再接入索引和 RAG。

- `standards/`：石油行业标准、录井技术规范和地质资料规范。
- `company_rules/`：公司制度、管理办法和质量要求。
- `excellent_reports/`：脱敏后的优秀报告与写作样例。
- `templates/`：报告、标书、合同和汇报模板。
- `report_templates/`：既有报告模板兼容目录，后续逐步迁移到 `templates/`。
- `tender_cases/`：脱敏后的标书审核案例。
- `contract_cases/`：脱敏后的合同审核案例。
- `expert_experience/`：专家经验、审核要点和人工确认边界。

## 入库原则

1. 不存放未经授权的敏感资料。
2. 资料入库前应脱敏并记录标题、版本、来源和适用范围。
3. 回答和审核必须标明来源；没有可靠来源时不得编造标准或制度。
4. 历史案例和专家经验只作辅助，不覆盖当前文件原文和现行制度。
